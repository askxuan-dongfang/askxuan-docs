## 1. 目标与确认事项

完成设计并下单，经付款和款式、用料、价格确认，形成可分享和复用的定稿。广场展示定稿，我的设计管理可编辑稿；后续同款使用与返现可追溯，二次编辑不改变别人已看到或购买的款式。

用户选择“订单已付款，且款式、用料和价格已确认后”。对应既有真实付款成功、商家/管理端审核进入制作及正常后续履约状态，不增加另一套确认步骤。模拟支付不满足发布条件。

同时恢复绿金手串装饰，统一首页四入口与下方的字体/无外框样式，精简师傅筛选，将成长规则融入等级权益。

## 2. 信息架构

| 页面 | 核心内容 | 操作 |
| --- | --- | --- |
| 首页 | 轮播、四个等大纹样入口、五类信仰、心愿 | 寺院/师傅/DIY/积分平级，全站搜索 |
| DIY 广场 | 紧凑珠环装饰、搜索、定稿作品 | 点击只读详情，复制至个人编辑器 |
| 我的设计 | 同样紧凑装饰、设计列表和发布状态 | 卡片直达编辑，独立发布/发布新定稿/下架 |
| 公开详情 | 预览、作品名、作者、用料、材料参考价 | 复制并编辑、按此款定制；本人也只读 |
| 编辑器 | 无框大画布、材料、估价和底栏 | 保存草稿、去定制 |
| 成长中心 | 档案、任务、明细、等级权益四入口 | 权益下方当前规则和历史版本 |

## 3. 发布状态与异常

| 状态 | 反馈 | 操作 |
| --- | --- | --- |
| 无本人同款订单 | 付款并确认后可发布 | 编辑、去定制；禁止发布 |
| 未付款/模拟付款 | 服务端付款原因 | 查看订单或编辑 |
| 已付款待确认 | 等待款式、用料和价格确认 | 查看定制进度 |
| 已付款且确认、草稿配方相同 | 可以发布 | 核验后确认发布 |
| 已发布且草稿相同 | 已发布 | 编辑、下架 |
| 已发布后修改 | 已发布 · 草稿已修改 | 保存不改旧定稿；符合资格后发布新定稿 |
| 取消/售后/退款中或完成 | 当前不可发布原因 | 保留本人草稿，停止相关公开读取和新归因 |
| 资格缺失/网络失败 | 资格暂不可用，可刷新 | 禁止发布，保留设计 |
| 并发修改 | 需要刷新当前版本 | 不覆盖其他端修改，不显示虚假成功 |

每次打开管理弹窗刷新服务端资格；提交时再次事务核验。客户端不得根据订单数量、按钮点击或本地布尔值判断已付款。失败保留原状态并提供刷新。

## 4. 定稿、价格与版本

定稿冻结珠子顺序、材料规格、绳线、手围、松量、描述与确认订单价格快照。配方匹配忽略临时槽位 ID、缓存位置、图片和渲染字段；保留影响款式的顺序/规格。价格明细的材料、规格、数量及合计必须与配方一致，版本号仅用于并发和追溯，不能代替内容核验。

公开材料参考价和单价来自同一确认订单，不混加持或运费。新订单仍核验库存、当期价格、等级优惠与券，以收银台为准；没有新增永久锁价承诺。

编辑只更新个人稿。公开详情显式读取已发布版本，即使本人登录也不显示未发布修改。发布新定稿新增不可变版本并切换公开指针，旧定稿不覆盖。下架保留草稿、已有订单及历史返现凭证。

没有合格定稿记录的旧公开作品停止广场展示，本人仍可编辑后按新规则发布。不批量伪造确认订单，不删除旧财务流水。

## 5. 复制与返现归属

| 情景 | 资格与归属 |
| --- | --- |
| B 复制 A，不下单 | 只有个人稿，无发布资格 |
| B 同款真实付款并确认后发布 | B 可分享，原定稿返现受益人仍为 A |
| C 再复制 B 的同款 | C 仍需自己付款确认，返现来源仍为 A |
| B 改珠序/规格/绳线/手围/松量 | 不沿用旧款资格；重新付款确认后成为新款来源 |
| 购买者使用有效定稿 | 订单绑定不可变版本与受益来源，不追逐可变草稿 |
| A 发布新定稿，B 已复制 A 的旧定稿 | 旧来源继续有效，前提是 A 未下架且旧定稿确认订单仍有效；不要求 B 改绑新版 |
| 作者后续改稿/下架 | 不覆盖已有订单快照，原订单按既有规则结算/退款冲回；不产生新的失效来源归因 |

公开作者与返现受益来源分开，不通过同款转发洗归属。自购、模拟支付、退款、观察期、比例、上限、净材料费基数和提现渠道沿用既有规则，不新增收益保证或回算旧账。

发布或新下单与退款同时发生时，以事务取得的有效状态为准：退款先完成，停止新发布及新归因；下单先完成，保留该订单已冻结的有效来源。不能只在打开页面时核验资格。

## 6. 首页与目录

首页四入口、分组标题、信仰和心愿共用页面内容边线，各区不再叠加水平内缩。四入口固定 2×2、等宽等高，背景透明，不保留块状底色或外框；右侧屋檐/人物/珠串/星纹低对比底纹保留。首页标题和入口使用现有宋体家族，底纹只作装饰，不替代图标、文字或触控区。

| 元素 | 标准尺寸与对齐 |
| --- | --- |
| 核心入口 | 最小高 104px，上下内距 16px、水平 0；图标 32px、标题 18px，内部间距 10px；行距 12px、列距 24px |
| 分组标题 | 20px，距下方内容 12px；分组间距 28px |
| 信仰 | 最小高 84px，上下内距 14px、水平 0；标题 16px、说明 12px，列距 24px；正文与裸字间距 8px，裸字 24px、透明度 0.65，无徽标小框 |
| 心愿 | 默认三列，最小高 56px、列距 12px；图标 22px、文字 14px、间距 8px，整项左对齐 |

信仰与心愿无包框、底色和竖分隔，仅用留白和轻横线组织行。手机信仰按 2+2+全宽排列，民间信仰末行左右边界与整个网格一致。宽屏 H5 在 1024px 断点重排为五列信仰、六列心愿；核心入口保持两列。窄屏与大字允许内容增高、说明换行，心愿按可用宽度重排，不缩小字号挤入固定高度；触控区至少 44px/pt，无裁切和横向溢出。

浅深色共用全部布局尺寸，只替换现有主题颜色。浅色沿用奶油白、墨绿、柔金；深色背景 `#1C1210`，文字 `#F0E6DA`、次级文字 `#C5B097`，沿用朱砂与柔金强调色。主题切换不改变字号、间距、网格与对齐。

原型“宽屏首页”只用于审阅，把预览区放宽；按预览容器实际宽度达到 1024px 才重排，不强制溢出窄窗口。该开关不进入产品。原型示例、真实 H5 与原生运行验收分别记录。

2026-10-21 按用户更正，找师傅侧栏只保留“提供服务”“价格区间”，提供服务默认展开，价格默认折叠。服务选项取平台 `/service-types` 标准目录，不随当前地区或结果数量缩减；用 `serviceCode` 匹配师傅已启用的 `serviceTags`（兼容既有未返回状态的标签），状态为 `nil`/空/`enabled` 的标签兼容可用，其他显式状态不能命中。服务与顶部类型/宗派/地区、价格和关键词取交集；清除服务只清除该条件，空结果保留选项与选中状态。H5 刷新保留有效条件，标准目录加载后清理未知服务编码；“全部清除”重置全部筛选。卡片有服务筛选时优先显示所选服务，再补另一启用服务；未选时按原顺序显示。不改变起价、折扣或预约规则。

移除身份/职位筛选，继续不显示擅长筛选和演示副标题；旧 URL 的 `position`、`specialty` 参数不能形成隐藏过滤。身份保留为资料字段，不新增师傅自行修改身份的能力：现有后端资料更新只开放部分字段，不包含 `position`。侧栏标题单行，展开不改变宽度；寺院目录不在本轮更正范围。此口径取代前轮“保留身份、移除服务”的方案，旧验收报告仍说明当时版本。

## 7. DIY 装饰与成长导航

广场/我的设计恢复绿金珠环和“一珠 / 一心意”，装饰约 100–112px，紧凑顶区约 112–144px，窄屏和大字可适配。保留设计按钮，不恢复旧大幅宣传区，装饰不可误作可操作手串。

成长中心只有“成长档案、成长任务、成长明细、等级权益”。权益下方折叠呈现获取/入账、升级、折扣和历史规则；优先当前有效规则，历史版本保留生效时间、明细、分页、失败重试。旧 `tab=rules` 及查看当前规则跳权益并展开定位。服务方规则职能保持，五级阈值、获取值、折扣上限和生效时间不改。
