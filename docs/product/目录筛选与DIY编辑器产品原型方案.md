## 1. 目标与使用者

找寺院、找师傅的用户先选五大信仰类型，再从所属宗派或信俗中细选，减少重复筛选层级。DIY 用户围绕手串预览和材料库完成设计，常驻界面只展示当前任务必要的信息。

后台运营为宗派 / 信俗设置一个所属类型。标签可多选关联到寺院和师傅；此处调整筛选层级，不修改已有提供者分类、服务能力、标签关联或订单。

## 2. 页面与信息架构

| 页面 | 从上到下的布局 | 主要操作 |
| --- | --- | --- |
| D01 找寺院 | 导航 → 五类标签 → 当前类型的子标签 → 地区 → 服务与结果列表 | 类型 / 宗派 / 地区 / 服务组合筛选，进入寺院详情 |
| D02 找师傅 | 导航 → 五类标签 → 当前类型的子标签 → 地区 → 身份、擅长与结果列表 | 类型 / 宗派 / 地区 / 身份 / 擅长组合筛选，进入师傅详情 |
| D03 筛选标签管理 | 宗派、身份、擅长分组 → 标签表格 → 新增 / 编辑表单 | 宗派必须设置所属类型；可更名、排序、启停 |
| B01 东方珠作 | 导航 → 手串名称 / 颗数 / 手围 → 预览 → 材料搜索 / 五行 → 左侧分类、右侧材料 → 金额与保存 / 定制 | 选材料、点选 / 拖动珠子、查看珠子菜单、撤销重做、保存、去定制 |

### 两级筛选的交互规则

1. 默认“全部”，不显示子标签区，也不保留独立“宗派 / 信俗”筛选栏。
2. 点击五类中的任意类型，在其正下方展开对应子标签并立即筛选该类型全部结果。
3. 子标签第一项为“全部 + 当前类型”，随后是该类型启用的宗派 / 信俗。点击子标签进一步筛选。
4. 切换类型清除原子标签；点击同一类型保留子标签。点击顶层“全部”同时清除类型和子标签。
5. 地区、服务、师傅身份和擅长筛选独立保留。无结果时保留全部筛选项和选中状态，提供清除筛选入口。
6. H5 URL 保存类型与宗派编码。刷新保持选择；仅带宗派的旧链接自动补齐所属类型；旧 `sect` / `type` 链接归一化。不属于当前类型、停用或未知的宗派会被清除，避免不可见的筛选条件。
7. H5 子标签换行，长列表在有限高度内滚动；iOS 使用横向滚动子标签行。展开位置、选择规则和数据相同，适配各端原生交互。

## 3. DIY 编辑器页面规格

| 区域 | 展示与操作 | 状态及反馈 |
| --- | --- | --- |
| 手串预览 | 名称、颗数 / 60、手围入口；台面、复位保持原位置 | 空设计展示开始提示；材料选择实时进入预览 |
| 预览右下角 | 撤销、重做并排常驻 | 无历史时禁用；新增、复制、删除、换位可撤销重做 |
| 选中珠子菜单 | 选中后预览左上角出现省略号入口；打开显示名称、位置、前移 / 后移、复制、删除 | 首尾换位禁用，库存或 60 颗上限时复制禁用；未选中时不展示 |
| 材料分类 | 左侧竖排：全部、主珠、隔珠、佛头、三通、吊坠、流苏、绳线 | 高亮当前分类；独立滚动；右侧材料结果随选择刷新 |
| 搜索与五行 | 材料库上方保留名称 / 规格搜索及五行选择 | 组合筛选；空结果可清除筛选 |
| 草稿 | 后台自动暂存，刷新可恢复；保存设计仍执行云端保存流程 | 移除常驻“已保存到本机”成功文案；本机存储失败显示明确提醒 |
| 底部操作 | 材料预估金额、保存设计、去定制 | 保留登录、库存、保存错误、手围和定制前校验 |

删除预览下方的操作提示 / 选中操作栏，以及带序号的珠子缩略序列条。珠子点选与拖动仍在预览完成；H5 预览可获得键盘焦点，以左右键选择、Alt + 方向键换位、Delete 删除，保留全局撤销快捷键。iOS 提供原生菜单和可访问的珠子选择入口。

## 4. 通用状态与全端一致性

| 场景 | 处理 |
| --- | --- |
| 游客 | 可使用目录筛选和本机 DIY 草稿；云端保存、定制仍走已有登录流程 |
| 筛选目录加载失败 | 列表与错误分别展示，提供重试；不把错误等同于空结果 |
| 语言 / 主题 | 跟随平台偏好；简体、繁体、浅色、深色使用同一套交互；不转换用户输入或业务编码 |
| 小屏 | 保留可滚动分类与材料库；金额操作区可见；不依赖横向页面溢出 |
| 数据一致性 | 五类和标签归属来自服务端；H5 / iOS 使用同一 `beliefCode` 和 `traditionCode`；独立筛选条件互不重置 |
| 不含该页面的端 | 法师 iOS / 服务方管理台没有客户目录与 DIY 编辑器，不增加无关入口；共用语言词表仍覆盖对应展示 |

## 5. 验收标准与交付边界

- 两个目录的五类子标签归属正确，切换清除旧子项，独立筛选保留；旧链接和刷新行为正确。
- 后台新增 / 编辑 / 停用标签验证归属，旧客户端更名不会清空已配置归属。
- DIY 不再出现三处冗余栏，历史按钮在预览右下角，分类竖排。
- 删除界面后的添加、复制、删除、换位、撤销重做、草稿恢复仍可完成。
- 320px / 390px、简繁体和深浅主题分别检查；iOS 编译、模拟器操作与商店发布分别记录。
- 数据迁移只新增父类型元数据，重复执行不覆盖已有归属；发布前备份、校验契约，发布后核对版本和在线行为。
