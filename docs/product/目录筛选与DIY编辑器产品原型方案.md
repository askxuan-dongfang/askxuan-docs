## 1. 目标与使用者

找寺院、找师傅的用户先选五大信仰类型，再从所属宗派或信俗中细选，减少重复筛选层级。DIY 用户围绕手串预览和材料库完成设计，常驻界面只展示当前任务必要的信息。

后台运营为宗派 / 信俗设置一个所属类型。标签可多选关联到寺院和师傅；此处调整筛选层级，不修改已有提供者分类、服务能力、标签关联或订单。

## 2. 页面与信息架构

| 页面 | 从上到下的布局 | 主要操作 |
| --- | --- | --- |
| D01 找寺院 | 导航 → 五类标签 → 当前类型的子标签 → 地区 → 服务与结果列表 | 类型 / 宗派 / 地区 / 服务组合筛选，进入寺院详情 |
| D02 找师傅 | 导航 → 五类标签 → 当前类型的子标签 → 地区 → 身份、擅长与结果列表 | 类型 / 宗派 / 地区 / 身份 / 擅长组合筛选，进入师傅详情 |
| D03 筛选标签管理 | 宗派、身份、擅长分组 → 标签表格 → 新增 / 编辑表单 | 宗派必须设置所属类型；可更名、排序、启停 |
| B01 东方珠作 | 导航 → 手串名称 / 颗数 / 手围 → 预览 → 材料搜索 / 五行 → 左侧分类、右侧材料 → 金额与保存 / 定制 | 选材料、点选 / 拖动珠子、查看珠子菜单、撤销重做、保存、去定制 |

### 两级筛选的交互规则

1. 默认“全部”，不显示子标签区，也不保留独立“宗派 / 信俗”筛选栏。
2. 点击五类中的任意类型，在其正下方展开对应子标签并立即筛选该类型全部结果。
3. 子标签第一项为“全部 + 当前类型”，随后是该类型启用的宗派 / 信俗。点击子标签进一步筛选。
4. 切换类型清除原子标签；点击同一类型保留子标签。点击顶层“全部”同时清除类型和子标签。
5. 地区、服务、师傅身份和擅长筛选独立保留。无结果时保留全部筛选项和选中状态，提供清除筛选入口。
6. H5 URL 保存类型与宗派编码。刷新保持选择；仅带宗派的旧链接自动补齐所属类型；旧 `sect` / `type` 链接归一化。不属于当前类型、停用或未知的宗派会被清除，避免不可见的筛选条件。
7. H5 子标签换行，长列表在有限高度内滚动；iOS 使用横向滚动子标签行。展开位置、选择规则和数据相同，适配各端原生交互。

## 3. DIY 编辑器页面规格

| 区域 | 展示与操作 | 状态及反馈 |
| --- | --- | --- |
| 手串预览 | 名称、颗数 / 60、手围入口；台面、复位保持原位置 | 空设计展示开始提示；材料选择实时进入预览 |
| 预览右下角 | 撤销、重做并排常驻 | 无历史时禁用；新增、复制、删除、换位可撤销重做 |
| 选中珠子菜单 | 选中后预览左上角出现省略号入口；打开显示名称、位置、前移 / 后移、复制、删除 | 首尾换位禁用，库存或 60 颗上限时复制禁用；未选中时不展示 |
| 材料分类 | 左侧竖排：全部、主珠、隔珠、佛头、三通、吊坠、流苏、绳线 | 高亮当前分类；独立滚动；右侧材料结果随选择刷新 |
| 搜索与五行 | 材料库上方保留名称 / 规格搜索及五行选择 | 组合筛选；空结果可清除筛选 |
| 草稿 | 后台自动暂存，刷新可恢复；保存设计仍执行云端保存流程 | 移除常驻“已保存到本机”成功文案；本机存储失败显示明确提醒 |
| 底部操作 | 材料预估金额、保存设计、去定制 | 保留登录、库存、保存错误、手围和定制前校验 |

删除预览下方的操作提示 / 选中操作栏，以及带序号的珠子缩略序列条。珠子点选与拖动仍在预览完成；H5 预览可获得键盘焦点，以左右键选择、Alt + 方向键换位、Delete 删除，保留全局撤销快捷键。iOS 提供原生菜单和可访问的珠子选择入口。

## 4. 通用状态与全端一致性

| 场景 | 处理 |
| --- | --- |
| 游客 | 可使用目录筛选和本机 DIY 草稿；云端保存、定制仍走已有登录流程 |
| 筛选目录加载失败 | 列表与错误分别展示，提供重试；不把错误等同于空结果 |
| 语言 / 主题 | 跟随平台偏好；简体、繁体、浅色、深色使用同一套交互；不转换用户输入或业务编码 |
| 小屏 | 保留可滚动分类与材料库；金额操作区可见；不依赖横向页面溢出 |
| 数据一致性 | 五类和标签归属来自服务端；H5 / iOS 使用同一 `beliefCode` 和 `traditionCode`；独立筛选条件互不重置 |
| 不含该页面的端 | 法师 iOS / 服务方管理台没有客户目录与 DIY 编辑器，不增加无关入口；共用语言词表仍覆盖对应展示 |

## 5. 验收标准与交付边界

- 两个目录的五类子标签归属正确，切换清除旧子项，独立筛选保留；旧链接和刷新行为正确。
- 后台新增 / 编辑 / 停用标签验证归属，旧客户端更名不会清空已配置归属。
- DIY 不再出现三处冗余栏，历史按钮在预览右下角，分类竖排。
- 删除界面后的添加、复制、删除、换位、撤销重做、草稿恢复仍可完成。
- 320px / 390px、简繁体和深浅主题分别检查；iOS 编译、模拟器操作与商店发布分别记录。
- 数据迁移只新增父类型元数据，重复执行不覆盖已有归属；发布前备份、校验契约，发布后核对版本和在线行为。

实际检查结果、Git 版本、ECS 发布号及尚未观察的范围只在验收记录中列明。原型通过不等于生产验收，模拟器通过不代表已发布 App Store / TestFlight。

## 6. 2026-10-20 截图评审：下一版优化建议

本节保留用户提供“珠了个珠”截图后的评审依据。用户随后已授权按该方案实现，当前完整规格与进度转入 [无框 DIY 与轻量导航 v2](无框DIY与轻量导航产品原型方案.md)，不混入上文 v1 验收数量。对比依据为用户截图、问玄东方线上 390px / 320px 页面与现有建模代码。小程序窗口在置前后仍连接超时，因此没有完成其交互体验；截图只能证明静态布局，不能判断它使用图片、2.5D 或真实 3D，也不能证明性能、手势与保存行为。

### 页面与操作

| 优先级 | Before：当前观察 | After：建议规格 | Why：目的 |
| --- | --- | --- | --- |
| P0 | 预览包在带边框、圆角、独立标题底色的卡片中 | 手机端移除预览外框，与页面共用暖白底色；标题、手围悬于画布顶部，材料面板保留一个分区边界 | 减少多层容器，让手串成为视觉中心；不需要复制竞品中央品牌标识 |
| P0 | 撤销 / 重做已在右下，但 390px 下会盖到靠右下的珠子 | 工具继续在右下，场景自动构图预留工具安全区；旋转、缩放和 60 颗场景均检查遮挡 | 保留用户指定的位置，同时保证珠子可看、可点 |
| P0 | 显示颗数和手围；已有适配结果在移动端底栏被隐藏 | 顶部只增加一个紧凑结果：“偏短 / 合适 / 偏长”；点击手围查看目标手围、松量、估算内周长及差额 | 用户需要知道能否佩戴；颗数不能替代长度。结果标注估算，不把模型长度当成实物测量 |
| P1 | 点击珠子后只出现省略号，操作入口不够直观 | 选中珠子高亮并显示一个清晰的编辑入口，菜单内保留替换 / 复制 / 删除 / 换位；只在首次使用给轻提示 | 不恢复已删除的常驻操作条和序号条，同时保证新用户能发现编辑方式；“替换”为新增待实现能力 |
| P1 | 材料竖排分类已上线；窄屏部分名称截断 | 保留左分类、右材料；名称最多两行，规格与价格固定位置；增加“已用”筛选，最近使用按后续数据能力补充 | 比照截图的“正在使用”入口，提高回找效率；不照搬冗余按钮或默认改变现有分类 |
| P1 | 画布和材料库高度固定分配 | 先做当前结构的留白和高度优化；需要细看时提供扩大预览，后续再评估可拖动材料面板 | 保证 320px 首屏能看到材料和底部金额操作，不先增加手势复杂度 |
| P1 | WebGL 异常文案仍提及已经删除的“下方珠子列表” | 改为保留设计、重载预览的准确说明；设计非 WebGL 的编辑降级入口 | 异常状态不能引导用户寻找不存在的界面；此项为代码审查发现，未制造生产上下文丢失 |

手机布局顺序为导航 → 名称 / 手围与长度状态 → 无框画布及角落工具 → 搜索 / 五行 → 竖排分类与材料 → 金额 / 保存 / 去定制。价格继续保留在底部，避免像参考截图那样重复增加价格栏。桌面保留画布与材料左右分栏，iOS 使用同一信息和状态，不要求逐像素照搬 Web。

### 建模与材质

现有 H5 已采用真实 3D：旋转体网格带贯穿孔，支持按珠径排布、绳线、物理材质、环境光、接触阴影及旋转缩放；因此不需要为了“有 3D”重做一套引擎。当前不同类别仍较多依赖通用轮廓，吊坠主要通过缩放处理，流苏为简化线束，这些与真实配件形态有差距。

| 优先级 | Before：当前观察 / 实现 | After：建议规格 | Why：目的 |
| --- | --- | --- | --- |
| P0 | 线上紫檀高光集中，木纹较弱，材质卡片与 3D 观感不完全一致 | 用同一材质资产和灯光基准校准缩略图与 3D；区分木料哑光、玉石温润、透明水晶、金属反射 | 优先解决“看起来像同一种塑料”的风险；依据实物照片校准，不凭材质名称统一调亮 |
| P0 | 圆珠与部分桶珠 / 隔片可参数化，三通、佛头、吊坠缺乏专用结构 | 圆珠 / 桶珠 / 隔片保留参数模型；三通增加实际孔路，佛头、吊坠、异形珠使用独立模型和安装锚点 | 让配件外形、朝向、穿线位置与真实商品相符；无需每颗标准圆珠单独制作高模 |
| P1 | 圆环排布按直径及形状系数估算，余线平均分配 | 统一毫米尺寸、轴向厚度和连接锚点；不足量时保留可见空绳，满串避免穿插；挂件在连接处自然下垂 | 保留尺寸真实性，避免自动铺满后误以为已达到佩戴长度；无需引入实时软体物理作为首版前提 |
| P1 | 同类珠子共享贴图，已有方向变化；材质内部纹理仍可能重复 | 合法实拍或自有贴图，少量有种子的纹理偏移和色差；保存后稳定复现 | 形成自然差异，同时保证再次打开、缩略图和其他端看到同一设计 |
| P1 | 混合珠径共用同一中心高度，阴影基面按最大珠径设置 | 明确是悬空编排还是平放展示；平放场景按各部件底面计算接触位置，并统一光源和阴影方向 | 减少小珠悬浮、阴影脱离、材质过曝；不同时混用两套物理暗示 |
| P2 | 已有按需渲染和纹理共享，未完成本轮低端真机性能测量 | 以真实低端手机验证首次可编辑时间、拖动响应和内存；低性能设备提供简化材质或 2D 编辑降级 | 是否需要 2D 由兼容性和测量决定；截图不能证明竞品性能更好，也不能据此删除现有 3D |

下一版建议先完成无框画布、工具避让、佩戴结果可见，再校准常用五类材质和三通 / 佛头 / 吊坠模型，最后补已用筛选和性能降级。模型验收至少覆盖 6 / 8 / 10 / 12mm 混珠、薄隔片、三通、吊坠、流苏、透明与不透明材质，以及添加 / 换位 / 保存恢复后跨端同序同尺寸。上述工作需要单独排期，未计入 v1 通过数量。
