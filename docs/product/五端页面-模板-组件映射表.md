## 1. 状态说明

| 状态 | 含义 |
|---|---|
| 专项完成 | 页面已做结构、移动任务卡、数据状态或运行时契约等专项重构 |
| 共享完成 | 页面已迁入统一壳层、主题、断点与状态体系，原业务组件和接口保持不变 |
| UI 已验收 | 使用本地 Mock 契约完成目标视口截图、无页面横向溢出、无未豁免控制台错误 |
| 待联调 | 需要 ECS 真实账号、真实业务数据或外部 Provider 才能确认，不等同于未完成 UI |

统一责任人记为“前端/Codex”。截图根目录为 `askXuan-frontend/e2e/artifacts/web/`，具体命名规则见[五端视觉回归与业务闭环用例](./五端视觉回归与业务闭环用例.md)。
