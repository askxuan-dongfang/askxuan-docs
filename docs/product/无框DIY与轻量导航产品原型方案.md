## 1. 产品目标与范围

用户在上半部直接看到手串，角落工具不遮挡珠子，添加材料时持续得到估算长度反馈。减少重复标题、独立框线和挤动列表的筛选层。个人成长与积分并列展示，避免单独成长卡破坏账户区的排列。

| 产品形式 | 本轮适用内容 | 验收口径 |
| --- | --- | --- |
| 客户 H5 | DIY、目录、商城、成长与公共控件 | Ego 浏览器多视口、主题与语言验收 |
| PWA / 内嵌 Web | 同一客户或服务方 H5 产物 | 共享实现；未单独运行安装态 PWA 或 WebView 容器验收 |
| 服务方 H5 | 共用下拉与取消规范 | 样式源码覆盖；本轮未逐页跑服务方业务流程 |
| 客户 iOS | DIY、目录、商城与成长入口 | 本任务专用模拟器、模型单元及 5 项 UI 用例 |
| 法师 iOS | 无上述客户页面；原生菜单与取消沿用已有系统样式 | 无本轮对应源码变更，未运行新的原生验收 |
| 平台 / 商城 / 寺院 Web | 共享运营控件 | 两套构建；平台本地交互验收，两套后台线上控件交互验收 |
| macOS 管理门户 | 嵌入同一运营 Web 产物 | 共享实现；未单独启动 macOS 容器验收 |

本轮保持成长等级、获取规则、优惠范围、积分兑换、订单金额、库存和保存权限的既有服务端规则。统一使用“成长值”；入口不改称“功德值”，避免把个人成长记录误解为宗教评价或可兑换资产。

## 2. 页面规格与用户路径

| 编号 / 页面 | 信息顺序 | 核心路径 |
| --- | --- | --- |
| B02 东方珠作 | 名称 / 颗数 / 手围 → 长度估算 → 无框预览及角落工具 → 搜索 / 五行 → 竖分类与材料 → 金额 / 保存 / 定制 | 添加材料 → 查看长度 → 点珠子编辑 → 保存或去定制 |
| D04 找寺院 / 找师傅 | 导航 → 五类标签 → 地区 → 侧筛与结果；子派别为覆盖层 | 点击父类型 → 悬浮层选子项 → 在原位置查看结果 |
| S02 商城 | 搜索与购物车同排 → 类目 / 排序 → 商品 | 搜索商品或进入购物车；底部导航承担“商城”位置提示 |
| P02 我的账户 | 头像 / 资料 → 成长值、积分、优惠券同排 → 钱包 / 服务进度 / 订单等 | 点击成长值 → 既有等级、权益及成长记录详情 |

### B02 无框工作台

| 区域 | 规格 | 异常与边界 |
| --- | --- | --- |
| 上部画布 | 去掉外框、独立标题底色和嵌套卡片，与页面共享主题底色；桌面允许与材料区左右排列 | 保留明确的上部预览与下部材料分区；不删除首页作品卡等无关容器 |
| 工具避让 | 上部工具、右下撤销重做使用独立保留区域；渲染画布实际缩入安全区 | 放大、旋转、缩放、最大颗数时仍不能让珠子位于工具点击区域下方 |
| 长度反馈 | 持续显示“内围预估”和偏短 / 合适 / 偏长；目标内围 = 手围 + 松量。允许偏差统一为 ±8mm | 差额只用于设计估计。非圆珠、穿绳、松紧及实物误差仍需制作确认；不承诺实际佩戴合适 |
| 珠子编辑 | 点选后显示清晰编辑入口，支持替换、前移、后移、复制、删除；撤销重做覆盖上述修改 | 首尾换位禁用；库存及 60 颗上限按现有规则处理。替换计算库存时扣除被替换那颗，不新增序号条 |
| 材料面板 | 左侧竖分类，右侧材料列表；名称最多两行、规格和价格有独立位置；提供“正在使用”筛选 | 无匹配结果说明筛选状态；删除后已用列表及时刷新；保留文字和键盘可操作入口 |
| 扩大预览 | 在当前页面扩大预览，可返回正常编辑布局 | 不丢失选择、材料、手围、历史和草稿；不新增与拖珠冲突的面板拖动手势 |
| 草稿与异常 | 继续本机自动暂存，失败时提示；WebGL 失效保留设计并提供实际可用的降级编辑和重载入口 | 不再提示寻找已删除的“下方珠子列表”；失败降级与正常 3D 必须分别验收 |

### D04 悬浮子派别

1. 点击五类父标签选择该类型并打开其下方悬浮层，层不占布局高度；地区、侧栏和结果列表的位置不变。
2. 同父类型再次点击可收起或重新打开，已有子项保持。切换父类型清除旧子项；顶层“全部”清除两级选择。
3. 子项首位为“全部 + 当前类型”，选择后立即收起。点击外部或按 Escape 收起；外部关闭不误触进入结果详情。关闭后键盘焦点可回到触发项。
4. 移除打开、关闭和筛选选中动画；选中态仍有底色和文字区别。长列表有受限高度及独立滚动，窄屏不横向溢出。
5. 地区、服务、身份、擅长独立保留。刷新与旧链接还原选中条件，但不自动打开覆盖层。

### S02 商城顶栏

删除内容区最顶部“商城”标题。搜索占可用宽度，购物车为同排固定点击区；数量为零时仍可进入购物车，非零数量和无障碍名称保持。搜索提交、清除、排序和商品详情路径不变。320px、长搜索词、较大购物车数量需检查同行与无溢出。

### P02 成长入口

| 状态 | 成长统计 | 点击行为 |
| --- | --- | --- |
| 已登录且加载完成 | 显示真实成长值，位于积分左侧；成长值 / 积分 / 优惠券同规格对齐 | 进入现有成长详情，查看等级、升级进度、权益及记录 |
| 加载中 / 请求失败 | 显示占位或重试提示，不把失败当成 0 | 详情页保持已有加载、错误和重试处理 |
| 未登录 | 不展示个人虚假数值；沿用登录引导 | 登录后在“我的”点击成长值进入详情 |
| 切换账号 | 清理前一账号成长缓存，按当前身份重新加载 | 不泄漏另一账号的等级、余额或记录 |

独立“我的成长”横卡移除；钱包、服务进度、订单和积分中心入口继续保留。各入口文案使用简繁词表，用户名称和业务编码不做汉字转换。

## 3. 轻量控件规范

| 控件 | 常态 | 聚焦 / 错误 / 禁用 |
| --- | --- | --- |
| 下拉选择器 | 无装饰描边，通过底色、当前值和箭头识别；下拉层用轻阴影区分前后 | 保留清晰键盘焦点；错误保留提示与错误边界；禁用有可辨透明度且不可操作 |
| 取消按钮 | 文字层级、透明底色，不与主提交按钮争夺注意 | 保留足够点击区域、焦点轮廓与禁用状态 |
| 原生控件 | 遵循同样层级，系统菜单、取消按钮使用原生轻量样式 | 不为去边框而移除 VoiceOver、键盘或系统错误反馈 |

只处理对应控件，不清空全局边框色。表格、输入验证、分隔线、卡片和选中状态仍按原语义展示。macOS 门户中的业务控件随共享 Web 样式更新，系统原生窗口装饰不作为业务控件强行覆盖。

## 4. 材质与配件模型规范

标准珠使用参数化几何与孔洞。母珠 / 佛头、三通、吊坠、流苏使用独立几何和连接位置，H5 与 iOS 从同一资产和毫米参数读取。母珠指手串结构配件，不绘制宗教人物肖像。

| 对象 | 必要表现 | 长度计算 |
| --- | --- | --- |
| 圆珠 / 隔片 / 桶珠 | 实际直径与穿孔，规格中的轴向长度影响外形；纹理稳定不随换位跳变 | 按沿绳方向实际占宽参与估算 |
| 母珠与三通 | 三向连接结构、可贯通孔路、朝向跟随绳路 | 使用连接处占宽，不简单按球形最大直径累加 |
| 莲花 / 葫芦 / 平安扣 / 木鱼吊坠 | 吊环、垂挂主体、独立轮廓与连接方向 | 垂挂长度不虚增腕内围，按挂接位置占宽 |
| 流苏 | 上部连接头、束线及下垂尾部 | 尾部长度不计为环形腕围 |
| 木 / 石 / 半透明 / 金属 | 粗糙度、反射、颜色深浅有区分，透明物避免纯白塑料外观 | 材质不改变交易价格与材料编号 |

配件网格由项目自建，材料缩略图使用同一形体。既有授权纹理继续保留来源说明；程序模型代表类别形态，不宣称与单件实物扫描一致。两端采用不同渲染引擎，透明折射不要求逐像素一致，但形状、尺寸、顺序及连接关系必须一致。

## 5. 验收与发布要求

- Web：320 / 390 / 768 / 1440px，浅深主题、简繁语言；所有新增入口可操作且无页面横向溢出。
- DIY：空设计、6 / 8 / 10 / 12mm 混珠、薄隔片、长桶珠、三通、母珠、各吊坠、流苏及 60 颗；选中、替换、复制、删除、换位、撤销重做和草稿恢复。
- 目录：五类子项、URL 还原、独立条件、选后关闭、外点和 Escape、不挤动下方筛选；iOS 对照同样状态。
- 商城 / 成长：搜索、购物车、成长详情导航、数值对齐、游客及账号隔离。
- 控件：客户、服务方及两管理台的下拉与取消抽样，正常 / 聚焦 / 错误 / 禁用状态。
- 分开记录单元测试、本地模拟交互、ECS 线上只读检查及 iOS 模拟器；不把模拟支付、模拟数据或构建成功记为真实业务履约。
- 使用各自 Git 仓库提交代码与维护文档，ECS 发布前校验当前版本、构建清单与回退点；生产不修改用户保存的设计。iOS 构建与模拟器交付不等于 TestFlight / App Store 发布。
