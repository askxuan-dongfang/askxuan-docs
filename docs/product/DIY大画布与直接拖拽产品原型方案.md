## 1. 产品目标

手串应成为页面上半部的主体。用户直接抓住珠子调整位置或移走，不需要先点开另一层编辑菜单。默认状态就能看清手串，扩大预览作为补充功能。

此次保留 v2 的无框底色、长度反馈、竖向材料分类、共享几何与材质、金额及保存流程。移除可见的“编辑珠子”入口和每颗珠子的额外操作按钮；不再把替换、复制作为可见主流程承诺。键盘与 VoiceOver 保留等价的移动、删除和撤销能力。

广场用于发现作品，详情用于看作品和复制创作。自己的作品即便出现在广场，也不在那里放编辑和发布管理。真正的编辑与公开状态管理统一进入“我的设计”。删除大段英文、长营销说明和重复的等级价解释，保留能帮助选择作品的必要信息。

## 2. 页面 B03：东方珠作

| 区域 | 页面规格 | 验收方式 |
| --- | --- | --- |
| 导航与摘要 | 页面标题、作品名 / 颗数、手围和内围估算保持紧凑 | 文字不覆盖珠子，长名称不会挤出手围入口 |
| 上半部预览 | 与页面同底色，无工作台外框；同时增加实际渲染容器高度和手串可见尺度 | 390 × 844 CSS 视口下，默认实际渲染高度目标不低于 300px；旧版约 192px 仅为对照测量，不能用外层空白冒充渲染增大 |
| 工具 | 复位、预览缩放等角落工具留独立操作区；撤销 / 重做位于右下 | 静置珠子及有效换位落点避开工具；按控件不会触发拖珠，已捕获的拖珠经过工具也不误点按钮 |
| 拖动反馈 | 拖动中的珠子跟随手指 / 指针；可换位时标出落点；待删时变色并提示“松手删除，移回取消” | 反馈只在当前手势中出现，不增加常驻编辑面板或序号条 |
| 长度与金额 | 始终显示已提交设计的内围预估和金额 | 拖动预览不改变设计数据；提交换位 / 删除后同步更新，撤销后恢复 |
| 材料区与底栏 | 搜索、五行、竖分类和材料列表保留；金额 / 保存 / 定制可达 | 小屏材料区可独立滚动；不依赖额外点“扩大预览”才能看清手串 |

390 × 844 为基准；同时检查 320px 窄屏、较短手机、横屏、768px 平板和 1440px 桌面。桌面可继续左右分栏，不能仅为了复用手机高度而制造大片空白。实际比例、手串可见边界及工具避让须在运行截图中核验。

## 3. 直接操作路径

| 操作 | 用户路径 | 提交结果 |
| --- | --- | --- |
| 选中 | 轻点珠子 | 仅选中与无障碍播报，不弹出编辑菜单 |
| 换位 | 抓住珠子 → 沿手串移到目标位置 → 松手 | 按落点插入新顺序；材料标识、数量和价格不变 |
| 删除 | 抓住珠子 → 拖出手串外沿 → 出现待删提示 → 松手 | 只删除这一颗；长度、金额和“正在使用”同步更新 |
| 取消待删 | 拖出后保持按住 → 移回安全范围 | 待删提示消失；继续换位或回到原位置松手 |
| 中断手势 | 拖动中按 Escape、指针取消、失焦或出现第二个触点 | 整个手势取消，设计、顺序与撤销栈均不改变 |
| 恢复 | 删除或换位后点击撤销 | 一步恢复该次完整操作；重做再次应用同一结果 |

第一次使用可有短暂的操作提示；不要恢复常驻的“点选珠子编辑”说明条。删除不弹确认框，依靠明确的待删反馈、松手提交和可见撤销避免误操作。

## 4. 全端手势契约

| 判断 | 统一规则 |
| --- | --- |
| 起拖 | 命中珠子后，指针位移 **≥ 6 CSS px / iOS pt** 才进入拖动；小于阈值视为点选 |
| 拖动锚点 | 珠子投影中心加本次指针位移，保留按下位置与珠心的偏移；不能让边缘点选造成珠子瞬移 |
| 冻结快照 | 起拖时冻结视角与屏幕投影，记录完整绳圈、真实珠子和配件外沿的凸包；本次手势内不随候选顺序重算边界 |
| 删除边界 | 锚点到上述凸包外侧的最短距离 **严格 > 24 CSS px / iOS pt** 才进入待删；等于或小于 24 取消待删 |
| 安全区域 | 凸包内部、边界和手串内孔均不是删除区；长吊坠、流苏和非球形配件的真实外沿参与边界计算 |
| 提交时点 | 仅正常 pointer up / 手势 ended 提交一次；拖过边界本身不会删珠，pointer cancel 不得按松手处理 |
| 相机与多指 | 单珠拖动期间视角冻结；第二指到来取消整个拖珠事务，再由既有视图规则处理后续手势，不能转成删除提交 |
| 历史 | 每次有效换位 / 删除只产生一条历史；原位置松手、取消、中断均不产生历史；撤销恢复原位置与材料标识 |
| 降级 | WebGL 失效后的平面预览使用同样的换位、删除与取消规则；无法获得有效边界时宁可取消，不能猜测删除 |

24px 是相对完整外沿的额外安全距离，不是从手串中心计算的固定半径。拖入手串中间空白处只能参与换位或保持原位。空设计、单珠及最大 60 颗均需单独检查；最后一颗删除后进入可继续添加的空设计，不出现失效选中项。

## 5. 无障碍与主题语言

珠子本身可以获取键盘 / VoiceOver 焦点，不额外绘制每颗珠子的编辑按钮。方向键选择，Alt + 方向键移动，Delete 删除；命令撤销及可见撤销 / 重做沿用现有规则。原生使用可读材料名称、顺序及自定义移动 / 删除动作，删除后焦点落到相邻珠或空设计。

待删状态同时提供文字、形状 / 轮廓与颜色反馈，不能只靠红绿色差异。正常、待删、取消和完成反馈使用简繁文案与当前主题；业务材料名和标识不进行任意转换。状态播报不在每个移动像素重复，控件保留焦点可见性。

## 6. B01 广场、B04 作品详情与 B05 我的设计

| 页面 | 信息顺序与密度 | 主操作 |
| --- | --- | --- |
| B01 DIY 广场 | 紧凑标题 / 搜索 → 作品列表；不保留占据首屏的大幅 Hero、英文眉题或长口号 | 浏览作品、打开详情、进入我的设计 / 开始设计 |
| B04 作品详情 | 作品预览 → 作品名与作者 → 用料；底部单一创作动作 | 复制并编辑，创建属于当前用户的副本；不在详情修改原作品 |
| B05 我的设计 | 紧凑页头 / 新建入口 → 本人设计列表；正常公开 / 私密设计明确“已发布”或“未发布”，既有 `rejected` 状态显示“已下架” | 点击作品卡直接进入 DIY 编辑器，不经过详情；发布 / 下架保留在列表的独立操作区 |

作品详情仅用于广场 / 分享浏览，无论是否本人作品都使用相同只读结构，不出现“继续编辑”“发布”“下架”等管理按钮；作者本人也通过“我的设计”完成这些动作。我的设计作品卡直接进入编辑器，未发布和已发布都不跳详情；点击发布 / 下架按钮不触发卡片编辑。删除重复等级价说明，不修改真实报价和等级优惠规则。

当前作者接口只提供 `userId`：本人显示“作者：我”，其他人显示“作者：创作者 #用户ID”；不臆造昵称。原型中的 #2 / #3 是明确的示例标识。将来如果接口提供正式展示名，可据新契约替换。

### 已发布作品的二次编辑

沿用已核实的现有保存合同，不新增发布快照或后台规则：

| 时点 | 我的设计状态 | 广场状态 |
| --- | --- | --- |
| 打开已发布作品编辑，但未保存 | 仍为已发布 | 既有公开作品保持不变 |
| 取消编辑 / 离开而不保存 | 仍为已发布 | 不更新或下架公开作品 |
| 确认保存修改 | 保存接口将作品设为私密，卡片显示未发布 | 原公开作品从广场移除 |
| 在我的设计重新发布 | 显示已发布 | 以重新发布后的内容公开展示 |
| 在我的设计下架 | 显示未发布，可继续编辑 | 从广场移除 |

对已发布作品点保存时明确提示：**“保存后作品将转为未发布，并从广场移除。完成修改后，请到‘我的设计’重新发布。”** 用户取消此保存步骤则不提交修改。原型演示同样的本地状态转移，不能暗示保存会自动同步公开版本。

## 7. D05 找寺院 / 找师傅：类型与地区同行

本节承接 v2 的无动画宗派浮层。仅调整地区入口位置、浮层协调与左侧服务字号，不改变五大类型 / 子派别归属、地区数据及既有筛选条件含义。

| 区域 | 统一规格 | 边界 |
| --- | --- | --- |
| 类型行 | 五大宗教 / 信俗类型位于左侧可横向滚动区；同一行最右侧固定“定位图标 + 地区”按钮 | 地区按钮不参与标签横向滚动，也不挤到第二行；窄屏优先压缩左侧可滚动宽度 |
| 地区按钮 | 未筛选显示“地区”；选中后显示当前地区名，超长文字截断但无障碍名称完整 | 定位图标仅表示地区筛选入口，点击不自动请求定位权限或改用“附近”筛选 |
| 地区浮层 | 点击按钮在类型行下方靠右悬浮，列出既有地区和“全部地区”；选择后关闭并刷新结果 | 不占文档流，不移动下方服务栏和结果列表；无展开 / 收起动画；原独立地区整行删除 |
| 浮层协调 | 地区和宗派 / 信俗浮层互斥；打开其中一个立即关闭另一个 | 同按钮再次点击收起；点击外部只关闭，不穿透打开列表详情；Escape 关闭并将焦点还给触发按钮 |
| 服务侧栏 | 左侧“服务”等分组标题与其筛选标签使用协调的同一文字层级，主要用字重区别标题 | 保留可点击标签、选中态及无障碍焦点；不出现标题明显小于标签、字号跳变的观感 |

地区、宗教类型、子派别、服务、身份与擅长仍独立保存。打开 / 关闭浮层不清空条件；选择“全部地区”只清除地区。切换父类型只按既有规则清除不属于它的子派别，不重置地区。刷新或旧链接还原筛选值，但不自动展开浮层。

地区加载失败在浮层内显示重试，已选值不擅自归零；已有未知地区编码保留清除入口。浮层宽度受可用视口约束，长列表内部滚动。客户 iOS 使用同样的同行入口、互斥覆盖层和关闭逻辑，不能通过原生页面重排再次把列表推下。

原型“找寺院 / 找师傅”两个入口共用这一交互，沿用 v2 五类示例数据。它只演示静态示例地区与标签，不请求定位、不调用地区或目录业务接口；实际地区数据、URL 保留、加载失败和两端行为仍须产品验收。

## 8. H01 首页四入口与 S03 分层搜索

### 首页核心入口

按“找寺院、找师傅、DIY 手串、积分中心”的顺序，固定为等权 **2 × 2** 四卡（逐行阅读）。四卡同宽同高，常规高度约 96–104px，图标尺寸、点击区域和文字层级一致，只显示图标与名称。删除入口副标题和独立积分横条，不在积分入口再单列积分余额、转盘 / 商城 / 奖池介绍或额外视觉强调。

四卡各有低对比原创底纹：寺院为建筑屋檐，师傅为人物线稿，DIY 为手串圆环，积分为星纹。底纹置于背景且不参与点击，图标与名称位于前景；四卡遵循同一主题配色和视觉分量，允许墨绿与金色的轻微底色区分，不让纹样压住文字。深色主题使用对应低对比线条，名称仍须清楚可读。

系统 / 应用大字体模式仍为 **2 × 2**，顺序不变，按文字尺寸同步增高四卡；不以缩小字体或裁字保住固定高度。各端沿用已有主题、语言、入口目的地与游客访问规则；积分入口不展示虚构个人数值。此变化仅合并首页核心入口，不删除积分中心内部功能或“我的”账户统计。

### 搜索范围与结果

| 搜索入口 | 搜索范围 | 条件关系与结果 |
| --- | --- | --- |
| 首页搜索 | 17 个固定功能入口与下表 7 类公开内容 | 功能与内容分类展示；点击功能进入对应页面，点击内容进入该内容详情；不受之前某个目录页的筛选限制；不索引私人记录 |
| 找寺院内搜索 | 仅寺院，覆盖名字、标签、可提供服务和地区名称 | 四类字段之间按任一匹配；关键词结果再与当前类型 / 子派别 / 地区 / 服务筛选取交集，不混入师傅、商品或功能入口 |
| 找师傅内搜索 | 仅师傅，覆盖名字、标签、服务和地区名称 | 与当前类型 / 子派别 / 地区 / 身份 / 擅长 / 服务 / 价格等既有条件取交集，不混入寺院或全站其他内容 |

首页搜索整合既有接口，本轮不新增后端搜索接口。功能入口共 17 个：找寺院、找师傅、DIY 手串、积分中心、商城、AI 问事、我的成长、我的预约、商城订单、定制订单、收货地址、我的设计、我的收藏、对话、大师广场、钱包与创作收益、活动奖池。入口沿用真实路由和现有登录要求；能搜到“我的预约”“对话”等功能，不代表可以搜索个人预约、订单、私聊、钱包记录或私有草稿的内容。

| 公开内容分类 | 初版索引范围与字段 | 完整性边界 |
| --- | --- | --- |
| 寺院 | 名称、地区 / 地址、宗教与宗派标签、服务名称 | 读取公开目录所有分页，并用类型、标签、服务、地区字典补充名称 |
| 师傅 | 法名 / 姓名、所属寺院、身份、擅长、宗教 / 宗派、地区、已启用服务名称 | 读取公开目录所有分页，不纳入私人咨询或非公开资料 |
| 服务与心愿 | 服务名称 / 编码；心愿名称 / 说明 | 使用既有服务字典与心愿标签集合 |
| 商品 | 商品名称、介绍、标签与分类名 | 读取公开商品列表所有分页 |
| 手串作品 | 已公开作品名称、介绍、标签与分类名 | 读取公开作品所有分页，不读取我的私有设计或草稿 |
| 动态 | 公开动态标题、正文、标签与分类名 | 读取公开动态所有分页，不包含私聊内容 |
| 推荐活动与专题 | 当前有效首页推荐内容的标题 | 复用首页推荐接口，仅搜索当前有效推荐集合；不是历史活动、所有专题或专题全文索引 |

寺院、师傅、商品、手串作品与动态按接口 `total` 连续读取全部分页，并按各类内容 ID 去重；该类完整装载成功后才给出结果或“没有匹配结果”。翻页失败、数据格式异常或未加载完整时显示该类错误与重试，不能把部分结果或零结果当成完整查询。其他成功类别仍可查看。结果中每类先显示 20 项，点击“显示更多”每次增加 20 项；这是已装载匹配结果的分段展示，与接口全量分页是两件事。

关键词及可搜索字段统一经 NFKC、OpenCC `t2cn` 简繁归一与大小写归一；这些转换仅用于匹配，不改动用户保存的名称或正文。空格分隔的多个词采用 AND：每个词都要命中至少一个字段，允许分别命中名称、服务、地区等不同字段。例如“禅修 香港”要求同一结果同时匹配两词。搜索框最多 80 个字符；空查询显示常用功能，输入查询后按上述公开内容分类检索。

目录搜索区文案分别使用“搜索寺院名称、标签、服务或地区”“搜索师傅名称、标签、服务或地区”，与首页“搜索功能、内容”区分，复用同一匹配规则。提交、清除、加载、空结果、失败重试均可操作；清除关键词只清除文字查询，不清空当前筛选。筛选值改变后继续按当前关键词查询；返回列表恢复当前查询和筛选。具体数据覆盖、分页、错误重试与简繁行为仍须逐端验收。

| 状态 | 页面反馈 |
| --- | --- |
| 关键词为空 | 全站搜索页显示常用功能；目录显示当前筛选下的列表 |
| 查询中 | 显示加载状态；不把尚未返回的数据当成零结果 |
| 有结果 | 首页区分功能与内容来源；目录只展示当前对象类型 |
| 无结果 | 显示真实空状态，允许修改关键词或调整筛选；不插入假结果 |
| 请求失败 | 展示错误及重试，保留关键词和筛选；不伪装为空列表 |
| 游客 / 需登录入口 | 公开内容按既有权限可见；受保护功能沿用登录引导，不展示私人记录 |

全端口径一致：H5、PWA、内嵌 Web 共用实现；客户 iOS 对照入口顺序、大字模式、全站 / 目录搜索范围及组合筛选。共享源码覆盖不代表每个独立容器已经运行验收。

上述初版范围已对照本轮 H5 实现草稿 `src/features/search/catalog.ts`、`src/features/search/pagination.ts`、`src/utils/directorySearch.ts` 与 `src/routes/customer/Search.tsx` 核实；这是源码合同核对，运行结果、接口权限、真实分页和 iOS 对照仍以验收记录为准。

## 9. 原型与产品的边界

v3 原型使用 SVG 与示例材料，演示实际 Pointer Events 交互及统一阈值；拖动会改变当前原型中的示例数组。切换深浅色、添加材料、撤销 / 重做、复制、保存与发布状态均只在内存中演示，刷新恢复初始示例，不读写用户草稿、云端设计或订单。

原型不是 3D 引擎、实物建模或业务接口验收。已有 v2 的商城与个人页五态通过链接继承；v3 首页与目录仅使用明确的本地示例，演示固定 2 × 2 四入口及原创纹样、大字适配、全站 / 局部搜索区别、地区同行和浮层协调，其 NFKC 与空格 AND 只匹配少量示例，未复刻 OpenCC 全字库、服务端分页和分类加载失败，不代表业务搜索验收。产品 H5、WebGL 降级与客户 iOS 仍须各自完成真实交互测试。

## 10. 验收清单

- 布局：默认渲染高度、手串占比、工具避让、材料可达；320 / 390 / 768 / 1440，浅深和简繁。
- 直接操作：真实命中珠子并拖动换位；拖出待删后松手删除；拖出再拖回；原位松手；删除最后一颗；撤销 / 重做保留标识和顺序。
- 几何边界：5.9 / 6px 起拖，外距 24 / 24.1px，内孔，旋转缩放后的形状，长吊坠 / 流苏，空 / 单珠 / 混珠 / 60 颗。
- 取消：Escape、pointercancel / gesture cancelled、失焦、多指、渲染丢失；不残留待删态，不生成历史。
- 无障碍：无可见编辑菜单；键盘、VoiceOver 的移动 / 删除 / 撤销路径可用，焦点不丢失。
- 广场与作品：首屏作品占比、精简顶区；本人 / 他人公开详情均只读，作者使用真实 ID；复制编辑不覆盖原作；我的设计作品卡直接进编辑器，发布操作不冒泡；已发布 / 未发布、二次编辑保存转私密、重新发布及下架按既有合同执行。
- 目录：两列表类型与地区同行；右侧入口固定，原独立地区行消失；两类浮层互斥、无动画、打开前后下方位置不变；选择 / 外部 / Escape 关闭，外点不穿透；独立条件和 URL 保留；服务标题字号与标签协调；窄屏、长地区名、加载失败与 iOS 对照。
- 首页 / 搜索：固定 2 × 2 等大四卡、常规 96–104px 与大字适配，四套原创低对比底纹不压文字，无副标题 / 单独积分横条；首页查功能与内容，目录仅查自身对象的名字 / 标签 / 服务 / 地区；组合筛选、清除、空态、错误、返回恢复、游客权限和分页；按端标明已观察范围，不能用示例原型或仅已加载内容代替全站搜索验收。
- 发布：各仓库提交与固定源码构建对应；H5 / iOS 证据、CI 与 ECS 线上复验分别记录。生产只读，不改用户 `design=23` 或已保存作品；iOS 源码与模拟器验证不等同商店发布。
