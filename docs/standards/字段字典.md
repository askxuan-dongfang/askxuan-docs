# 问玄东方 - 字段字典

> 本文档由 `askXuan-backend/db/init.sql` 的建表语句整理，作为各端、后端、产品原型对齐字段命名、类型、状态值和关联关系的字段级基准。
> 更新时间：2026-08-12。若修改数据库结构，应同步更新本文档和 `统一数据字典.md`。

## 0. 核心主数据约束

| 规则 | 字段 | 说明 |
|------|------|------|
| 寺院唯一编码 | `temple.code` | 所有端使用 `T001` 这类编码作为寺院业务 ID |
| 法师唯一编码 | `master.code` | 所有端使用 `M001` 这类编码作为法师业务 ID |
| 法师归属寺院 | `master.temple_code` | 必填，且只能引用一个真实寺院；寺院详情法师列表必须按此字段查询 |
| 一级信仰流派 | `belief_profile`、`temple.belief_code`、`master.belief_code` | 平台管理台维护主数据，寺院关联，C 端动态读取 |
| 寺院类型标签 | `temple.type`、`temple.sect` | 具体类型/宗派展示和兼容筛选使用 |
| 寺院服务标签 | `temple_service.service_code/service_name` | 找寺院服务筛选、寺院卡片标签、预约入口使用 |
| 管理账号绑定 | `admin_account.role_id/temple_id/master_id/shop_id` | 不同管理端登录后以绑定对象作为数据权限边界 |
| 用户端寺院可见 | `temple.status` | 仅正常/上架口径进入用户端 |
| 用户端法师可见 | `master.auth_status + shelf_status + platform_status` | 已认证、已上架、未封禁才进入用户端 |
