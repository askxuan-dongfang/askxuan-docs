## 5. 登录规则

- C 端使用 `POST /api/v1/auth/login`，手机号、密码登录；开发验证码固定为 `1234`。
- C 端注册使用 `POST /api/v1/users/register`，当前演示环境不验证真实短信；注册后 iOS/H5 自动登录。
- 平台、寺院、商城管理台与 Master App 使用 `POST /api/v1/auth/admin/login`，账号、密码登录。
- 停用账号返回错误码 `40303`，不能通过登录接口绕过审核状态。
- `admin` 用于平台管理台，`shop_admin` 用于商城管理台；寺院账号只能管理其绑定寺院，大师账号只能管理其绑定大师资料。
- MySQL、Redis、RabbitMQ、MinIO、OpenIM、SSH 等基础设施凭据不属于产品测试账号，不在本文记录或分发。
