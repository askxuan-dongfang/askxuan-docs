# 问玄东方产品使用手册

产品版本：**0.0.1**。

源码与入口核对日期：2026-09-16。适用于当前 H5 信众端、H5 法师端、两套 iOS 应用、统一运营管理台和寺院管理台的已实现功能。

本手册按当前代码中的入口和操作编写。看到“演示”“模拟支付”的页面时，应按演示流程使用；模拟成功不代表真实扣款。信众 iOS 最新对齐版已完成签名构建、安装及模拟器界面测试；安装后自动启动受设备锁屏阻止，登录业务仍待真机逐项验收。两款应用均不据此视为已在 App Store 发布。实际可用入口以您安装的版本、账号权限和当前上架内容为准。

## 1. 选择正确入口

以下地址为平台站点内的路径，请使用管理员提供的正式站点，不要把开发地址当作登录入口。

| 使用者 | 入口 | 主要用途 |
| --- | --- | --- |
| 信众用户 | H5 `/c`；问玄东方信众 iOS 应用 | 浏览寺院与大师、预约、AI 问事、对话、社区、商城、DIY、积分 |
| 法师或独立执业大师 | H5 `/m`；法师 iOS 应用 | 处理本人预约、消息与加持任务，管理日程、资料和收入 |
| 平台、商城运营人员 | `/admin/` | 统一运营管理台，按账号权限展示业务菜单 |
| 仍使用旧商城书签的人员 | `/shop/` | 经兼容迁移页进入统一管理台的对应商城页面；商城操作均在总管理台完成 |
| 寺院管理员 | `/temple/` | 本寺院资料、法师、服务、预约和加持任务 |

信众端底部是“首页、对话、AI问事、商城、我的”；法师端是“工作台、预约、消息、我的”。顶部搜索入口位于信众首页，可进入寺院搜索。订单、积分、地址、账号与外观设置主要从“我的”进入；DIY 从首页或商城中的 DIY 入口进入。

## 2. 登录、退出与会话失效

1. 信众从“我的 → 登录 / 注册”注册普通用户，填写用户名、邮箱、密码及页面所需验证码，完成邮箱验证。登录采用“用户名或邮箱 + 密码 + 图片验证码”；图片不清楚时刷新，邮件验证码用于注册、激活和找回密码。
2. 独立执业大师在大师端入口注册申请人账号，填写认证材料并提交审核；通过后才能进入大师业务工作台。寺院纳管大师由寺院管理台建立档案、分配账号，本人在同一大师端入口验证邮箱、设置密码激活并登录。
3. 寺院在 `/temple/` 注册经办人账号，提交机构资料与管理授权，经平台审核后成为寺院管理员。普通注册不直接获得业务权限。
4. 总平台仅保留内部管理入口，当前使用 admin 总管理员，不开放公众注册。各身份使用自己的入口与权限，不因邮箱相同自动合并账户。
5. 忘记密码时，选择“找回密码”，使用已验证邮箱接收验证码并设置新密码；改密后旧会话失效，需要重新登录。未接入短信时不依赖短信验证码。
6. 退出使用账号菜单中的“退出登录”。会话明确失效时回到相应登录页；网络错误、权限不足和聊天未连接分别处理。

邮件服务已接入生产 SMTP。普通用户使用本人可收信邮箱；占位测试邮箱不能用于收信或找回。测试凭据单独保存在私密账号文件，不进入本公开手册。
输错登录信息时，在登录页面更正后重试。“无此功能权限”表示账号权限不符合要求，应联系管理员；重复登录不一定能解决。网络中断或聊天暂未连接不等于账号已失效，先按页面的“重试”或“重新连接”处理。

不要把所有未提交内容都当作已保存。DIY 有本机草稿，聊天也有对应草稿提示；其他表单应以“保存成功”或已生成记录为准。重要订单提交结果不明确时，先查订单列表，避免再次新建。

## 首页与服务进度入口

首页集中展示找寺院、找师傅、信仰流派和八项心愿，DIY 前置；心愿无需横向滚动才能看全。寺院和大师目录的顶部流派筛选与其他服务、价格条件组合使用，不再用侧栏重复同一组流派。

游客可从首页进入 DIY 制作；保存到账号、个人作品和下单时按提示登录。信众“我的 → 服务进度”是固定入口，首页有进行中的预约时显示当前服务卡片。集中页可查看执行进度和回执档案；原服务订单详情仍保留完整流程。

## 3. 外观、标识与阅读

| 位置 | 操作 |
| --- | --- |
| H5 信众端 | “我的”页面底部选择“浅色、深色、跟随系统”；游客引导页也有外观设置 |
| H5 法师端 | “我的 → 设置 → 外观” |
| 信众 iOS | “我的 → 外观”；游客页面也可进入外观设置 |
| 法师 iOS | “我的 → 设置 → 外观”；登录页也有外观入口 |
| 统一管理台、寺院后台 | 使用登录页或页面顶部的“外观”选择器 |

浅色沿用东方珠作的奶油白、松绿和柔金；深色采用深棕、朱砂和暖金。选择固定浅色或深色后，页面按该选择显示；“跟随系统”随设备外观变化。外观偏好按当前浏览器或应用保存，不代表所有设备已经同步。

母品牌、信众端、法师端、东方珠作及后台使用同一套标识家族；标识差异用于区分产品入口，不表示用户等级、认证或账户权益。标题保留东方气质的衬线字形，正文和控件使用统一的易读字体层级。

页面切换、按钮反馈、弹层和加载状态使用短动画。希望减少移动效果时，可在设备的辅助功能中启用减少动态效果；iOS 同时支持系统动态字号，具体空间会随页面排版调整。AI 完整报告另有“放大字号”按钮。

iOS 桌面 AppIcon 的明暗由系统桌面外观决定；应用内手动切换主题不会单独切换桌面图标。

## 5. 常见异常怎么处理

| 看到的情况 | 建议操作 |
| --- | --- |
| 页面仍在加载，按钮暂不可点 | 等待当前操作结束；保留当前页面，避免重复提交 |
| 加载失败或“暂未加载” | 检查网络后使用页面重试；失败不表示记录被删除 |
| 同时存在旧记录和更新失败提示 | 旧记录仅供参考，重新加载后再确认最新进度 |
| 材料、商品或服务不可用 | 重新选择当前可用内容；旧设计和旧展示价不保证现在可下单 |
| 库存、价格或状态发生变化 | 按最新提示重新核对，不以截图或旧页面金额为准 |
| 操作提示成功，列表尚未更新 | 返回对应列表刷新，按订单号或报告标题核对 |
| 页面资源异常，提示“页面暂时无法显示” | 先确保需保留的内容已保存，再使用“刷新页面” |
| 摄像头、麦克风或附件不可用 | 查看系统/浏览器权限；不支持时改用页面提供的文件上传方式 |
| 功能入口不见了 | 先核对当前端、账号角色、安装版本及内容上架状态，再联系管理员 |

联系支持人员时，提供所在端、发生时间、页面提示、订单号或报告号等业务编号即可；不要发送密码、验证码或登录凭据。
