## 维护与生成

正文维护在 `docs/guides/`，必要图版维护在 `docs/assets/0.0.1/`，正式 PDF 输出到 `output/pdf/`。品牌资源以[前端 packages/brand](https://github.com/askxuan-dongfang/askxuan-frontend/tree/master/packages/brand)为准，不从 PDF 截图反向制作母版。

运行需要 Python 3、ReportLab、Pillow、pypdf、pdfplumber 和 Poppler。正文可通过 `HANDBOOK_BODY_FONT` 指定可嵌入 CJK TTF；品牌字通过 `HANDBOOK_BRAND_FONT` 指定。默认字体为 macOS Arial Unicode 和同级前端的 AskXuanSerif-Semibold.ttf；可通过 `ASKXUAN_FRONTEND` 指定源码位置。

```sh
python3 scripts/build-handbook-plates.py --frontend ../askXuan-frontend
python3 scripts/build-handbooks.py
python3 scripts/check-handbook-pdfs.py
node scripts/audit-markdown-links.mjs
```

图版脚本生成六张规范 PNG，页面 JPEG 保持实际观察日期。生成清单记录版本、源稿和 PDF 哈希。替换四册前，需检查渲染后的每页文字、表格、图片、图注、页码、目录及书签；只提取文字不足以证明排版正确。当前结果见[0.0.1 核验](../reports/0.0.1-核验.md)。
