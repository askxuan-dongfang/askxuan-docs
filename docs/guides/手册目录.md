## 更新方式

先修改 `docs/guides/` 中的手册正文及分册；页面变化时同步替换 `docs/assets/handbooks-20260913/` 对应截图，并更新图源与适用日期。规范示意由 `scripts/build-handbook-plates.py` 生成。正式品牌母版仍在前端 `packages/brand/`，不从 PDF 截图反向制作 Logo。

生成需要 Python 3、ReportLab、Pillow，以及渲染核验用的 Poppler；可使用 Codex bundled workspace runtime。正文通过 `HANDBOOK_BODY_FONT` 指定可嵌入的 CJK TTF，标题通过 `HANDBOOK_BRAND_FONT` 指定正式 AskXuanSerif-Semibold.ttf。默认正文为 macOS Arial Unicode（仅嵌入子集，不分发原字体文件），默认品牌字来自同级前端仓。可用 `ASKXUAN_FRONTEND` 指定前端路径。

```bash
python3 scripts/build-handbooks.py
node scripts/audit-markdown-links.mjs
```

输出位于 `output/pdf/`，生成清单记录源文件和 PDF 哈希。替换 PDF 前需用 Poppler 渲染全部页面，核对文字、表格、图片、页码、目录和书签；只检查文字提取不足以证明视觉排版正确。当前基线与核验结果见[手册更新核验](../reports/2026-09-13-产品手册与PDF更新.md)。
