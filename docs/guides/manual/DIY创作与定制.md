# DIY 创作与定制

[返回产品使用手册](../产品使用手册.md)

## 从一条手串开始

进入“东方珠作”，选择“开始我的设计”。也可以先浏览“设计广场”，打开喜欢的作品，再选择“复制并编辑”。复制会创建自己的设计，不会修改原作者的作品。

H5 首页提供“设计广场”和“我的设计”；iOS 的“我的作品”“灵感广场”提供对应入口。查看个人设计、保存到账号、复制和下单需要登录。

## H5 工作台操作

1. 在“挑选材料”展开材料库。五行筛选位于材料库上方，分类沿左侧纵向排列，右侧显示材料结果；可再输入材质或规格关键词。收起材料库后，可用分类下拉框和快捷材料条继续挑选。
2. 点击材料卡片加入珠子或绳线。卡片显示规格、单价和已选数量；达到库存或珠数限制时不能继续添加。
3. 在“珠序编排”点选一颗珠子，使用“复制、移除、向前移、向后移”调整。2D 画面也支持点选和拖动换位；顶部可“撤销、重做”。清空后仍可立即撤销。
4. 展开“佩戴尺寸”，选择手腕净围及松量，参考内围估算和尺寸提示。天然材料、配件和穿绳方式都会影响实物尺寸，预览不构成实物尺寸或纹理保证。
5. 通过“2D / 3D”切换预览；至少加入一颗珠子后才能进入 3D。3D 用于观察搭配，修改顺序时可切回 2D 和珠序控件。向下挑选材料后，可点击小预览返回手串区域。

五行色点和数量用于搭配分类与计数，不是测算、功效或结果承诺。未找到材料时，先清除五行、分类和关键词筛选；确实加载失败时使用“重新加载材料”。

## iOS 与 H5 的差异

| 功能 | 当前 iOS 操作 |
| --- | --- |
| 材料分类 | 横向分类按钮，展开后可搜索材质、规格；当前没有 H5 的独立五行筛选控件 |
| 串珠编辑 | 原生 2D 搭配：点按选中、拖动排序、移出圆环删除，也有复制和撤销等控件 |
| 3D | 已提供真正的原生 3D 环视，可拖动旋转、双指缩放；不应再按旧说明理解为仅 2.5D 效果 |
| 保存与广场 | 支持本机草稿、保存设计、发布/下架及复制；按钮文字和弹窗布局与 H5 略有区别 |
| 历史订单 | 从“我的”的订单列表查看 DIY 手串，打开详情查看进度及当前可用操作 |

## 草稿、保存和公开不是同一件事

- **本机草稿**：编辑时自动暂存未保存修改，页面显示草稿提示。只属于当前设备/浏览器环境，不保证换设备后可恢复。浏览器清理数据、无痕模式或本地存储不可用可能影响恢复。
- **保存设计**：点击“保存设计”，填写作品名称，可补充搭配灵感，再确认保存。出现成功结果并能在“我的设计/我的作品”找到后，才表示保存到账号。
- **公开作品**：在自己的作品详情选择“发布到广场”并确认，其他人即可查看、分享和复制。公开作品继续编辑并保存后会先转为私密，需要回到详情重新发布。

下架公开作品后，其他人不能继续打开其分享链接或复制；已经产生的副本与订单保留。分享私密作品前需先发布。浏览器不支持自动复制链接时，可使用显示的分享链接手动复制。

H5 作品详情可在 2D 模式下“导出图片”；导出是保存预览图，不是保存设计，也不是下单。

设计广场搜索针对已经加载的作品。没有搜到时，可以清除关键词或继续加载更多，不代表全站没有同名作品。

## 确认定制与订单进度

1. 从编辑器点击“去定制”，按提示先保存；或在作品详情选择“按此设计定制”。
2. 核对作品、珠数、材料明细、收货地址，以及是否选择额外加持服务。无需加持时选择“暂不需要”。
3. 查看材料费、服务费和最终合计。系统会再次核对材料上下架、库存、规格和最新价格；出现不可用材料时，返回自己的设计或先复制作品，替换后再提交。
4. 当前定制支付入口标注“确认并模拟支付”或“模拟支付”。这是演示支付，不产生真实扣款；下单会形成业务订单，因此也应核对地址和材料后再操作。
5. 在“DIY 订单”查看审核、制作、加持、待发货、已发货等进度。H5 可以展开订单详细记录；iOS 可以打开订单详情。支付或加载结果不明确时先刷新原订单，不要立即再次新建。
6. 订单已发货、且实际收到作品后，选择“确认收货”并确认。未收到时不要提前确认。

订单详情中的用料来自下单记录，最新材料目录可能已经变化；费用以该订单金额为准。加持凭证、物流和时间信息以实际返回记录为准，不应把空白字段理解为步骤已经完成。

当前顾客 DIY 页面主要提供支付、进度和确认收货，未提供普通商城那样的完整自助退货流程。需要取消、退换或退款时，携带 DIY 订单号联系运营人员；不要去普通商城订单中寻找同一笔 DIY 订单。后台拒绝待审核定制单与顾客自助申请售后是不同操作，退款进度还需单独核对。
