# 预约、商城、积分与活动

## 先分清六种记录

| 项目 | 用户获得什么 | 当前费用与记录规则 |
| --- | --- | --- |
| 服务预约、普通商城、DIY 定制 | 已选服务或商品的订单 | 按人民币标价；当前支付服务为模拟渠道，不能据此认为微信、支付宝或银行实际扣款已经接通 |
| 体验商品 | 用于体验下单、支付、发货和收货的模拟订单 | 明示模拟支付、模拟物流，不实际扣款、不实际发货；不发放消费积分，不记入真实营收口径 |
| 积分商城 | 标价明确的确定商品或权益 | 按兑换价扣积分，与随机抽奖不同 |
| 积分活动：幸运转盘、大奖池 | 一次参与机会，结果可能中奖或未中奖 | 当前每期明确扣除积分，不收现金；成功参与后无论中奖与否均不退分 |
| 免费或公益活动介绍 | 具体活动的时间、地点和安排 | 是否免费以该活动条款为准；通用活动详情目前是信息展示，不自动包含报名、抽奖或领奖流程 |
| 功德值、随喜 | 功德值记录成长；随喜为订单中的自愿金额项 | 功德值不支付、不兑换，不等同于余额或积分；随喜不存入“功德金钱包” |

“我的”页面的功德值当前可能显示“—”，表示成长记录尚未开放展示，不是待领取现金。个别订单仍使用“功德金”标签时，应结合该订单的随喜明细理解，不表示账户存在可充值、提现的功德金余额。

历史资料中的“免费抽奖”不能直接套用当前转盘与奖池。页面明确写有参与积分并要求确认扣除时，就是积分活动。奖品由平台预算承担，也不意味着参与时不消耗积分。

普通订单与体验订单的区别还在于账务处理：不能把体验订单“积分和财务不受影响”的说明扩展到全部普通订单。查看积分、订单和账务记录时，以对应业务类型为准。

## 预约服务

1. 在首页浏览寺院、大师或服务，进入详情，选择可预约服务。独立执业大师和寺院所属法师的服务入口可能不同。
2. 选择日期和可用时段，补充备注等要求；无可用时段时更换日期、服务或提供者。
3. 阅读费用汇总，区分服务费用、页面列出的执行费用及选填随喜。不要把个人功德值当作抵扣金额。
4. 确认信息后提交预约，查看结果中的预约号、日期、时间与金额，再从“我的 → 服务订单”查看后续状态。
5. 已完成的本人预约可评价：选择星级、填写内容并提交，每单一次；之后可查看法师回复。

页面提供“取消预约”时，先核对日期和服务，再确认取消。取消会改变预约状态并释放相应名额，不等于退款已经到账；当前取消流程不应被理解为已提供自动退款闭环。涉及款项问题，应按预约号联系运营并单独核对处理结果。

预约、支付、履约是不同状态。按钮写“确认预约并支付”或出现演示支付结果，不构成真实渠道扣款凭证。提交响应不明确时，先到服务订单查询，避免重复预约。

## 商城购买与售后

1. 进入“商城”，浏览分类或搜索，打开商品，核对介绍、图片、规格、价格、库存及是否标注“体验”。
2. 选择规格和数量，加入购物车或按页面入口结算。体验商品与普通商品需要分开结算。
3. 选择收货地址，核对订单明细和当前支付说明后提交。体验单只用于模拟流程，不会按该体验单真实寄出商品。
4. 从“我的 → 商城订单”或商城订单入口打开该笔订单，查看付款、物流和收货进度。支付处理中先查询原订单结果。
5. 对实际已经收到的普通商品，使用“确认收货”；体验单按模拟流程核对状态。

符合当前状态的普通商城订单可“申请售后”，填写原因并提交。等待审核后，按页面要求填写退货物流、查看商家收货及退款进度。提交申请、审核通过和退款完成是不同阶段，不要提前视为退款成功。体验单的对应流程仍是模拟流程。

商城售后不覆盖 DIY 订单。DIY 的处理方式见 [DIY 创作与定制](DIY创作与定制.md)。

## 积分获取与兑换

从“我的 → 积分”查看可用余额、明细、积分商城和兑换记录。

当前规则为每笔符合条件的订单实付满 100 元得 1 积分，不足部分舍去，例如 199 元对应 1 积分、200 元对应 2 积分。退款按净实付重新计算已获得积分，扣回后余额可能为负，后续获得的积分先补足。体验商品不参与消费积分奖励，积分到账以明细为准。

兑换操作：

1. 在“积分商城”挑选商品，查看所需积分、库存和说明。
2. 选择数量和收货信息，确认合计积分及兑换后余额，再提交。
3. 在“兑换记录”查看状态。待发货兑换如提供“取消兑换”，确认后会退回积分；已发货的兑换在实际收到后确认收货。

积分不足时不能兑换；余额加载失败不等于余额为零。先重新加载，查看具体明细后再处理。

## 幸运转盘与大奖池

从积分页进入“幸运转盘”或“大奖池”；活动中心还有“参与记录”“我的奖品”。

1. 阅读本期奖品、数量、开始/截止时间、名额、参与积分和规则。每个账号每期只能参与一次。
2. 点击参与，在确认弹窗核对本期扣分和剩余余额。参与成功会扣分，无论是否中奖均不退回；失败不扣分，重复请求不会重复扣分。
3. 转盘即时揭晓结果；大奖池先生成参与码，截止后开奖，不要求等到人数满额。
4. 到“参与记录”查看本期参与码和结果。转盘扇区是动画展示，不代表每个扇区实际等概率；页面会说明当前概率或奖池人数估算。
5. 中奖后进入“我的奖品”，填写收货人、联系电话和完整地址；已有地址可直接选择。提交前仔细核对，提交后不能把原领奖信息任意改成另一地址。
6. 查看待发货、已发货和物流信息，实际收到后确认收货。地址簿暂不可用时，可以按页面提示手动填写。

未中奖不退参与积分；功德值不变。活动结束、名额已满、已参与或积分不足时不能再次参加。网络错误时先查原参与记录，不要重复新建参与；中奖结果以记录为准，不以动画位置推断。
