# AI 问事、私聊与社区

[返回产品使用手册](../产品使用手册.md)

## AI 问事与模型选择

1. 登录信众端，进入底部“AI问事”。直接输入问题，也可以先选择页面提供的技能或专题。
2. 点击页面上方当前模型名称，打开“选择模型”；iOS 使用“模型”菜单。可用模型由当前服务提供，以页面实际列表为准。
3. 模型切换用于接下来的提问，已有回答不会重写。选择会在当前设备按账号记住；原选模型下架后，会改选当前可用模型。
4. 点击添加图片，检查待上传预览并移除不需要的图片。当前会话包含图片时，应选择支持图片的模型；仅文字模型会被禁用或提示切换。
5. 提交问题后等待回答。生成期间不要反复点击发送；失败时使用该条回答的“重试”。较长时间仍在生成时，可稍后从“历史问事”继续查看。

模型列表加载失败时，打开选择面板使用“重新加载模型”；显示最近可用列表时，以页面提示为准。关闭选择面板不会清空当前问题。发送失败后先核对是否已产生回答，再重试。

在“历史问事”可以重新打开会话。删除会话前会再次确认，应先确认不再需要该历史内容。聊天使用账户当前额度，选择模型不代表获得无限额度。

## 专题报告

专题报告与自由聊天是两种入口：自由聊天的模型选择不等于手动指定专题报告的生成模型。

1. 从 AI 页面“专题探索”选择主题，阅读摘要、章节说明和完整解读所需积分。
2. 按引导补充资料，再填写最想了解的问题。标注必填的内容需要补齐，不确定的选填项可留空。
3. 选择“生成免费摘要”。生成摘要不扣积分；生成期间可先进入“我的报告”，稍后再看。
4. 摘要完成后先阅读。需要完整解读时，查看积分余额，点击“解锁完整报告”，核对确认弹窗中的扣分和剩余积分后确认。
5. 已解锁报告可重复阅读。H5 可使用章节导航、放大字号、保存 Markdown 报告，并选择“围绕这份报告继续问事”；iOS 提供对应报告阅读入口，具体分享操作使用系统界面。

提交超时后，用“重试提交”或“我的报告”找原记录。生成失败可以“免费重试”；超过页面说明的等待时间仍未完成时，可使用“检查并恢复生成”。积分不足时摘要会保留，不必重复创建报告。已解锁的后续问事仍按账户正常聊天额度使用。

专题图案是视觉表达，不代表用户的实际排盘或抽牌结果；内容供传统文化参考，不承诺预测结果。

## 私聊、通知与附件

信众端进入“对话”，在“我的私聊”查看会话；“我的收藏”展示关注的法师/大师，“大师广场”用于浏览公开内容。法师端从“消息”进入通知和业务会话。也可从具体法师或预约详情进入可用咨询入口。

- 输入文字发送；需要图片、音频或文件时，通过附件入口先选取、预览，再确认发送。打开收到的图片可以查看大图。
- 录音需要麦克风权限。可先录制、检查再发送；点击取消不会发送。当前环境不支持录音时，按提示换用支持的浏览器或上传音频文件。
- 支持语音/视频通话的会话中，先允许麦克风、摄像头权限，再发起或接听；结束后点击挂断。真实可用性还取决于设备、网络和对方状态。
- 查看更早消息时，收到新消息不会强行把阅读位置拉到底部；点击新消息提示可回到最新内容。
- 消息显示“发送失败”或“结果待确认”时，使用原消息的重试操作，避免再手动发送一份。断网时保留的草稿和失败消息会有页面提示。

“正在连接”“消息同步中”是连接状态，不是付款、预约或登录失效结果。先检查网络或使用“重新连接”。私聊未读与系统通知是不同数据：信众私聊角标不能用通知总数理解；法师底部“消息”可能汇总通知和私聊，请进入后分项查看。

## 大师广场、关注与评论

1. 在“大师广场”选择“发现、关注、图文、视频”，可搜索关键词并切换最新/热门。
2. 打开文章或视频详情，浏览真实上传素材、作者资料，再选择点赞、关注或评论。点赞和关注可再次点击取消。
3. 视频可切换网格与沉浸浏览。素材加载失败时，按提示重试，不应把失败占位当作原视频内容。
4. 提交评论后可能显示待审核，提交成功不等于已经公开。不要为了让评论立即出现而反复提交。

公开社区页面可供游客浏览；从需要登录的“对话”入口进入或查看“关注”、点赞、评论时，可能出现登录引导。社区加载失败会提供重试，不等同于当前没有内容。

## 法师发布内容

法师端从“工作台 → 内容与直播”进入创作区，选择图文或视频，填写标题、正文和信仰流派。图文最多上传 9 张图片。H5 可在素材预览中调整顺序，第一张作为封面；iOS 使用系统照片选择器选取后上传，检查已上传数量和素材就绪状态。视频先上传视频文件，可设置封面并预览。

点击“保存草稿”可暂不公开；点击“提交审核”后等待审核结果。在“我的内容”查看状态和驳回原因，草稿或驳回内容可继续编辑，审核通过的内容可下架。不要把保存草稿或已提交审核当作已经发布。

直播入口需具备页面提示的直播能力和必要信息。只有功能已开放、资料有效时才发起，不将“直播”按钮存在视为摄像头、媒体链路或实际观众侧全部验收完成。
