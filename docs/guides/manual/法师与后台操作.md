# 法师与后台操作

## 法师日常工作

H5 与 iOS 法师端均使用“工作台、预约、消息、我的”四个主入口。寺院所属法师与独立执业大师的资料、服务和排班入口按实际身份显示，不要仅凭页面名称判断账号权限。

| 任务 | 操作步骤 |
| --- | --- |
| 处理预约 | 从工作台待办或“预约”筛选记录，打开详情，核对服务和时段；按当前状态依次“确认预约 → 开始服务 → 完成服务”，每次核对确认提示 |
| 设置日程 | 从工作台进入日历，选择日期和可预约时段，点击“保存日程”；“设置休息日”会清除所选日期的可预约时段，先阅读确认提示 |
| 处理加持任务 | 打开任务核对作品和服务；根据当前状态接单或拒绝，接单后开始加持；完成前上传所需凭证，核对后“完成加持” |
| 与用户沟通 | 在“消息”区分通知与私聊，也可从预约详情进入会话；录音和通话按设备权限提示操作 |
| 管理个人资料 | “我的 → 个人资料”修改可编辑信息；服务定价、标签、评价等进入对应菜单，保存后检查页面结果 |
| 查看收入 | 从“收入提现”或“我的”相关入口查看收入与记录；提现提交仅代表申请，实际到账需查看处理结果 |
| 发布图文、视频 | 从“工作台 → 内容与直播”进入，保存草稿或提交审核；详细步骤见 [AI 问事、私聊与社区](咨询与交流.md) |

任务状态决定当前可执行的操作。已拒绝、已取消或已完成的任务不能通过反复点击继续原来的流程。凭证上传失败时，先检查文件和网络；只有凭证已经上传、且完成动作成功后，才应对外表示任务已完成。

休息日设置不应被当作自动取消既有预约的按钮。对已经产生的预约，仍需到预约详情核对并按业务规则处理。

## 统一运营管理台

平台和商城运营从 `/admin/` 登录。旧 `/shop/` 书签会跳转到统一管理台；已经登录统一后台时，不会因为打开旧入口而自动换成另一位管理员。商城人员仍只访问被授权的商城功能，寺院业务继续使用寺院后台。

桌面可折叠侧边栏；窄屏通过菜单按钮打开导航。进入页面后先看标题、筛选条件和空状态，避免把筛选结果为空当作数据丢失。

### 商城与 DIY 运营

1. **商品管理**：进入“商城与权益 → 商品管理”，新建或编辑商品，核对名称、图文、分类、规格、价格、库存和体验标识，再保存及按需要上下架。
2. **积分商城**：在独立积分商城入口维护兑换价和库存，不把现金商品价格直接当作积分价。
3. **DIY 材料**：进入“DIY 与加持服务 → DIY 材料”，维护材料、规格、库存与渲染素材。变更后会影响新的选材和定制可用性，已生成订单仍依据其下单记录。
4. **加持服务**：在相邻服务入口核对服务说明、价格及提供方。服务上下架和材料上下架不是同一个操作。
5. **DIY 订单**：打开待审订单，核对设计与材料后通过或拒绝。通过后进入制作流程；完成制作、符合状态要求后再登记发货。
6. **履约与售后**：在“商城订单、物流与运费、退货售后”处理普通商城业务，按当前订单状态核对运单、退货与退款进度。

拒绝待审核 DIY 订单需要填写原因，会停止制作、恢复相关库存；已付款订单会进入退款处理，不能承诺操作后即时到账。DIY 发货前核对物流公司和运单号，发货后本页面不提供直接撤回。

### 平台审核、活动与模型

| 入口 | 操作要点 |
| --- | --- |
| 机构与人员 | 查询寺院、法师、用户与管理账号；管理范围以权限为准，独立执业大师与寺院法师按对应资料处理 |
| 审核中心 | 进入寺院审核、法师审核、评价或社区/短视频审核，打开详情核对真实文字与素材，按页面要求给出通过或驳回意见 |
| 首页活动与广告 | 核对标题、图片、目标页面和活动有效期，再保存或发布；保存配置不等于已经展示给用户 |
| 积分活动与奖品 | 创建转盘或奖池，填写奖品、平台预算、参与积分、名额和截止时间；保存为草稿，发布前再次核对 |
| 活动领奖订单 | 查询中奖和地址记录，再登记物流公司与单号；等待用户实际签收 |
| AI 模型设置 | 有权限的人员测试连接、读取可用模型，核对默认模型及报告配置，再“保存并生效”；只读提示下不能把填写完成视为配置已保存 |
| 财务中心 | 查看结算、对账及处理记录；申请、审核、支付状态和实际到账分别核对 |

当前积分活动发布后会冻结规则、时间、预算和奖品；仅无人参与时可取消。不要把“平台承担奖品预算”写成“用户免费参与”，参与积分需明确展示。

AI 设置生效后用于新的问事和报告，正在生成的回答不受这次切换影响。连接测试成功、模型可选与真实问事完成是不同结果；密钥不要复制到截图、工单或使用手册。

## 寺院管理台

寺院人员从 `/temple/` 登录，主要管理本寺院范围。

1. **寺院信息与图册**：核对介绍、联系方式等可编辑内容，上传合适图片，点击保存；返回展示页确认结果。
2. **法师管理**：查看或编辑本寺法师，核对资质、服务和状态。入驻或资质审核仍需经过相应审核流程。
3. **服务管理**：新建或编辑服务，核对价格、说明、可预约时段和上下架状态。已经下架的服务不会因为旧链接仍在而恢复可预约。
4. **预约管理**：筛选并打开预约，核对用户、服务、日期和状态，按页面操作确认或取消。取消和款项处理分别确认。
5. **加持任务**：打开可分配的任务，选择符合要求的法师，点击“确认分配”。后续在任务详情查看法师处理进度和已上传凭证。
6. **评价与报表**：查看真实评价、回复和数据范围；无数据时先检查日期及筛选条件，再确认是否确实没有记录。

## 操作异常与交接

- 操作失败先保留页面提示和业务编号，刷新当前记录核对是否已经成功，再决定重试。
- 权限提示应联系账号管理员处理，不使用别人的账号绕过权限。
- 发布、拒绝审核、发货、取消和完成动作都应先核对确认弹窗；页面按钮禁用时，先检查状态或必填项。
- 交接订单时传递业务编号、当前状态、已完成步骤和待处理事项，不传递密码或登录凭据。
- 当前页面和代码支持某项流程，不等于已证明所有生产支付、直播、物流和结算都经过真实端到端验收。需以对应业务记录和实际处理结果确认。
