# AI 问事智能体：使用、能力与验收

更新：2026-09-29。适用本次 Harness 版本的 H5、AI 服务与总管理台。部署版本和真实验收结果见[全工具接入记录](../reports/2026-09-29-taibu全工具接入.md)、[上下文升级记录](../reports/2026-09-29-Harness上下文升级.md)和[首版发布记录](../reports/2026-09-29-Harness发布.md)。本说明不包含账号口令、个人报告或模型密钥。

## 1. 从哪里进入

- 信众：登录后进入底部“AI问事”，选择“问事”直接输入问题，或在“发现 → 问事技能”选择具体能力。
- 报告追问：进入“我的报告”，打开已解锁报告，选择“围绕这份报告继续问事”。
- 总管理员：总管理台“AI 问事 → 智能体运营管理”，地址 `/admin/ai/operations`。模型连接由原“AI 模型设置”维护。

用户名/邮箱、密码和图片验证码沿用现有登录方式。本次没有重置管理员密码。智能体运营配置要求平台超级管理员，寺院或大师账号不能代替。

## 2. 普通用户怎么用

### 直接提问

先说明想解决的事情，例如“我在换工作和留下之间犹豫，帮我梳理判断标准”。这类问题可直接讨论，不强制排盘。需要实际计算时，智能体会选择当前启用的工具，读取结果后回答。

页面显示准备、判断下一步、读取报告、调用工具或生成回答等阶段。处理过程可能包含多个模型和工具步骤；没有逐字输出时也可能正在执行任务。不要反复发送相同问题。

### 缺少资料时

1. 从具体计算技能新建会话时，缺资料会直接显示“补充资料并继续”；普通问事由智能体按需补问。
2. 打开表单，检查已填内容，补充确知的日期、时间、历法或其他必要信息。
3. 点击“确认资料并继续”，本次资料随原会话保存，智能体围绕原问题继续执行。
4. 不知道必填信息时，不要猜测；可关闭表单，改为讨论一般性问题。关闭不会伪造计算结果，也不会清空已有会话。

已确认资料来自用户表单和关联报告原始资料，不从助手输出反推事实。资料只用于当前会话，尚无跨会话长期档案。刷新后从历史问事继续即可。

### 围绕报告继续问

先解锁报告，再由报告入口进入关联会话。例如“解释这份报告中已有的十神信息，哪些结论有工具依据？”智能体可以读取该会话关联的报告，并按需要追加已有工具支持的计算。

报告正文与原始资料分别处理。不会把报告中的推测当成新的出生资料，也不能通过输入其他报告编号读取别人的报告。每轮会重新核对报告归属与解锁状态。

八字命盘与大运是两个独立工具。询问大运、流年时，Harness 可继续调用 `bazi_dayun`，读取完整的大运、流年及太岁关系后回答；紫微运限和飞星也分别使用自己的工具。出生地点校正仍取决于 MCP 返回的地点解析状态，不能把“已填写地点”当作“已完成真太阳时校正”。

### 查看依据与处理失败

回答下方的“查看处理过程”展示实际工具调用及成功/失败状态；没有工具调用时会明确说明。它不展示模型隐藏思考链，也不等于专业结论认证。成功回答还展示上下文估算占用、有效窗口和输出预算；供应商返回的实际输入/输出 Token 另行展示，不能把估算值当成账单。

生成期间可以点击“停止生成”，停止后该消息保留并可重试。关闭网页不等于停止服务端任务；连接中断时页面会继续查询任务状态。

失败时使用原消息的“重试”，问题和报告仍在原会话。工具暂不可用时，智能体可在预算内再次尝试；没有结果就应说明限制。服务正在外部调用时若重启，不会假装已完成，也不自动无限重放请求。

## 3. 能力清单

| 能力 | 当前行为 | 边界 |
| --- | --- | --- |
| 多步执行 | 模型根据观察结果选择下一步，工具结果返回后可继续调用 | 每轮最多 4 次模型调用、4 次工具调用；默认任务时限 180 秒 |
| 一般问答 | 解释、梳理、文化交流，可直接回答 | 不必为了显得复杂而调用工具 |
| 关联报告 | 读取当前用户当前会话的已解锁报告 | 不支持任意报告编号、外部文档库检索 |
| 计算工具 | 15 个 taibu 计算工具全部适配；另有日常问事、姻缘、风水 3 项综合技能 | MCP 和具体技能必须可用；不等于工具支持全部推算项目 |
| 资料补问 | 结构化表单、条件必填、复用已确认资料 | 模型不能自行填入出生时间等事实 |
| 历史与继续 | 消息及资料持久化，刷新后可继续 | 用户下一轮重建上下文；不是外部模型请求断点续传 |
| 图片问事 | 延续已存在的最多三张图片与视觉模型支持 | 必须选择支持图片的模型 |
| 失败恢复 | 有限工具重试；思考耗尽且无答案时可进行一次兼容降级重试 | 不提高原 Token/次数上限，不把截断答案当完成 |
| 可观察性 | 阶段、工具记录、模型/工具次数、用量与配置单价费用 | 上游未提供 usage 时无法推算精确用量 |
| 运营管理 | 技能策略、版本快照、评测、分批放量、回滚与审计 | 保存草稿不等于对用户生效 |

日常问事、姻缘、风水属于综合对话技能，没有额外独立的计算引擎；按问题需要可使用已确认资料调用上述工具。梅花与六爻已拆开，不再把同一工具包装为两种计算。技能是平台审核的规则、输入契约与工具绑定；不是任意上传脚本或自动安装外部插件。

公历与农历不能混填；农历闰月尚无专门表单，需自行确认对应公历日期。西方占星的出生时间按出生地当地时间，流运时刻按表单标明的北京时间。经纬度必须由用户确认，系统不会偷偷使用默认城市。四柱反推只给候选，不自动写入原始出生资料。

当前没有任意联网搜索、RAG 知识库、跨会话长期记忆、多智能体协作、可视化流程编排、智能体付款或代下单。专题报告首次生成仍沿用原报告流程，报告后的多轮追问走 Harness。

原生 iOS 仍使用现有 API 和界面。本次新增的补充资料弹窗、处理记录展示首先交付 H5；不能宣传 iOS 已完成同样的交互验收。

## 4. 管理员怎么配置

### 模型连接

在 AI 模型设置中核对服务地址、密钥、默认模型、可用模型与输出额度。Harness 当前要求兼容 OpenAI 接口且支持工具调用的模型。普通连接测试只证明连接可用，应继续执行工具用例验证。

修改模型设置后，新请求使用新快照，正在执行的请求保留原快照。不要将 API Key 放入提示词、评测资料或文档。

### 上下文与生成额度

总管理台“AI 模型设置”可调整以下额度；修改后点击“保存并生效”，系统再次验证模型连接，新请求使用新配置。

| 设置 | 本次生产生效值 | 管理台范围与说明 |
| --- | --- | --- |
| 普通问事输出 | 8,192 Token | 64–32,768；每次模型调用的上限，可能包含思考 Token |
| 复杂分析输出 | 16,384 Token | 不低于普通额度，最高 32,768；关联报告、结构化计算资料或明确要求详细分析时使用 |
| 平台上下文 | 1,048,576 Token（1M） | 32,768–1,048,576；输入、历史、工具、输出及安全预留共同占用 |
| 单次输入 | 20,000 字符 | 2,000–100,000；字符数与 Token 数不是同一单位 |
| 异步任务时限 | 180 秒 | 60–600；每轮整体预算，并非每个模型调用重新计时 |

实际上下文取平台配置和所选模型声明容量的较小值；模型未提供容量时按 32K 保守处理。输出还受模型最大输出及可用窗口限制。供应商声明 1M 上下文不代表平台会生成 1M 输出，也不代表每次调用都发送满 1M 内容。

Harness 不再按固定最近 30 条、40KB 截断历史。每次模型调用前按预算组装上下文，优先保留系统要求、用户确认资料、当前问题以及当前工具调用与结果。必要时移除完整的旧轮次，余量允许时附上旧用户问题摘录。这是有限历史压缩，不是大模型摘要或跨会话长期记忆；当前轮次本身过大时会明确失败，不悄悄丢弃工具结果。

当前估算使用 UTF-8 字节保守计数，并为图片、工具定义和协议留量，不是 DeepSeek 精确分词器。实际计费用量以供应商 usage 为准。平台输出范围有意收敛到 32K；不能把供应商可能更高的最大输出量直接等同于默认预算。

发布的智能体版本可进一步收紧输出预算；需要放宽时，应修改草稿、重新评测并发布。后台单次快速调试仍有独立的 512 Token / 50 秒限制，整组评测也有总体时限，不等同于用户异步任务额度。专题报告首次生成使用复杂输出额度，报告追问使用 Harness。

### 智能体运营工作区

1. 查看工作区顶部实际运行模式。显示 Harness 才表示用户问事采用多步执行器。
2. “技能与工具”列出完整目录。已有草稿缺少新技能时，点击“将新技能加入草稿”，再检查提示词和开关；不会自动改动已发布版本。调整名称、全局要求、默认模型、输出额度、技能启停及提示词；工具地址沿用后端白名单，不能从页面任意添加执行程序。
3. 保存草稿。保存使用修订号校验，发生冲突时重新读取，不覆盖其他人的修改。
4. 使用合成资料调试。后台保留旧流程作为对照，单次调试成功不是发布凭证。
5. 为每个启用技能至少配置一条正常回答评测，再加入类型错误、禁止输出等用例。真实个人资料不要写进明文评测配置。
6. 运行整组评测，查看输出长度、必含/禁含内容、工具调用和失败原因。缺少资料引发补问，不能算“非法资料已拒绝”的通过用例。
7. 只有当前草稿、模型连接和执行引擎匹配，且 24 小时内评测通过，才能发布候选版本。

### 放量与回滚

有两个独立服务开关：`AI_HARNESS_ENABLED` 控制执行引擎；`AI_AGENT_OPERATIONS_ENABLED` 控制已发布配置是否接管用户请求。只启用前者时，用户已经使用 Harness，但沿用已有技能目录和配置。

管理台候选版本从 0% 开始，按账号稳定分桶；先完成测试，再按 10%、25%、50%、100% 逐步扩大。未命中的账号使用稳定版本或原始配置。每次修改比例填写说明。

旧普通问答引擎的评测不能用于 Harness 发布或激活。切换引擎、修改模型配置后需要重新评测。出现问题时可回滚历史配置或恢复原始配置；需要切回旧执行器时由运维关闭 Harness 开关并重建服务。

## 5. 怎么测试

以下是可重复执行的测试清单，不表示每条已在生产完成。执行证据和未验收项见发布记录。

| 场景 | 操作 | 应观察到的结果 |
| --- | --- | --- |
| 一般问题 | 新会话输入生活讨论问题 | 正常回答，可无工具调用 |
| 资料不足 | 请求排盘但不提交结构化资料 | 补问表单出现，不编造计算结果 |
| 补充继续 | 填入合成日期与时间并确认 | 保留原问题，执行工具后回答 |
| 报告追问 | 从自己已解锁报告继续问事 | 读取关联报告；无权报告不能读取 |
| 全工具覆盖 | 对 15 项工具使用合成资料测试 | 工具成功、有依据返回、处理过程名称正确 |
| 子选项 | 塔罗 9、梅花 8、六爻 4、飞星 4、太乙 5 种选项分别测试 | 仅展示对应资料，传参符合 MCP 契约 |
| 数字校验 | 占星纬度填 91、小六壬农历日填 31 | 资料拒绝，不继续计算 |
| 条件必填 | 六爻选择数字方式但不填数字 | 要求补充数字；改其他方式仅收集对应字段 |
| 失败重试 | 隔离环境模拟工具失败 | 有限重试或明确失败，不伪装成功 |
| 长输入 | 独立测试会话提交超过 2,000、少于 20,000 字符的合成资料 | 接收成功；上下文信息展示实际模型窗口 |
| 停止生成 | 生成期间点击停止，再按需重试 | 当前任务停止，消息保留；不能停止其他用户任务 |
| 历史压缩 | 隔离环境使用小窗口与长历史 | 旧轮次按预算裁剪，当前问题与工具配对保留 |
| 预算限制 | 隔离环境持续要求调用工具 | 达到上限结束，不无限调用 |
| 重启继续 | 在等待补资料时刷新页面 | 能找回会话并继续提交 |
| 移动输入 | 手机 Safari 打开补问表单 | 输入字体与弹窗可用，提交值完整；真机需独立验证 |
| 发布门槛 | 修改草稿或模型后直接发布 | 必须重新评测，不能复用过期或旧引擎通过记录 |
| 权限 | 非超管访问智能体运营接口 | 拒绝访问，不提升角色权限 |

这些测试涉及模型调用额度，但不需要真实支付或制造真实订单。生产测试应使用独立测试账号与合成资料，避免重放个人报告。
