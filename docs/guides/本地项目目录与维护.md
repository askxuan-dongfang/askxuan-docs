# 本地项目目录与维护

产品版本：**0.0.1**。工作区 `DongFang/` 本身不是 Git 仓库，源码在各独立仓库维护。

## 当前目录

| 路径（相对工作区） | 用途 |
| --- | --- |
| `askXuan-backend/` | 后端 main；业务服务、网关、部署脚本及配置 |
| `askXuan-frontend/` | 前端 master；两套 iOS、管理后台与共享视觉 |
| `askXuan-frontend/apps/web-h5/` | H5 独立仓库 main，需单独提交与发布 |
| `askXuan-docs/` | 本仓 master；当前手册、技术/API、部署和需求 |
| `askXuan-frontend/packages/brand/` | 唯一正式品牌母版、生成器与导出资源 |
| `artifacts/0.0.1/` | 工作区当前整理和发布的简短核验、manifest |

手册正文、图版、PDF 分别位于本仓 `docs/guides/`、`docs/assets/0.0.1/`、`output/pdf/`。需求从 [specs](../../specs/README.md) 进入，不在工作区另建任务板。AI 专题/MCP 运行依赖按后端当前配置维护，不能将独立产品的品牌或构建默认归入问玄东方。

## 同步与构建

开始工作时分别检查 Git 状态、HEAD、上游及嵌套 H5。只对干净且当前提交为上游祖先的目录执行快进；保留其他任务的未提交改动。任务隔离副本记录使用者、基线和嵌套仓库，结束前核对变更归属。

依赖与构建产物按对应应用的锁文件、脚本重建。H5 和后台在各应用目录安装依赖及构建；iOS 按[原生开发指南](iOS入门指南.md)重新生成产物。不能仅因某个 build 或 node_modules 曾存在，就把它当作当前验证结果。

发布配置、数据库、凭据、运行时卷与挂载不是普通缓存。清理前核对实际使用关系，不能对工作区执行全局 `git clean -fdx`。源码、当前手册和必要资源通过各仓库维护；当前核验记录中不混入过期任务路径。

## 文档检查

```sh
node scripts/audit-markdown-links.mjs
node scripts/audit-api-contracts.mjs ../askXuan-backend
```

API 审计覆盖 19 个业务服务的 383 个唯一 HTTP 契约，排除网关 health 和 OpenIM 透传；它不证明权限、设备和第三方交易均已验收。

发布及回滚见[GitHub Actions 与 ECS](../deployment/GITHUB-ACTIONS.md)。本地文档整理和业务服务部署分别记录，不以版本号代替发布回执。
