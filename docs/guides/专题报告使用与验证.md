# 专题报告：使用、能力与验证

更新：2026-09-29。发布与生产验收见[本次发布记录](../reports/2026-09-29-专题报告发布.md)。 原生 iOS 已同步报告优先结构，详见下方原生使用说明；旧专项 PDF 仍对应此前发布版。

## 页面保留关系

“专题”是默认入口，“问 AI”用于直接提问和报告追问，“我的报告”保存历史成果。原来七个专题均保留；新增五个专题。18 项底层技能的重复卡片从发现页收起，计算工具仍供 Harness 调度，不删除技能、聊天记录或报告。

## 信众怎么用

1. 进入 AI问事 → 专题，先展开“先看一份示例报告”。示例无需登录，均为原创版式和合成测试数据。
2. 选择专题并填写本人确认的资料。出生时间不确定时不要猜测。合盘分两组填写双方资料；择日可填 1–3 个候选日期。
3. 说明关注的问题（可选），点击生成。系统依次显示资料检查、计算、报告撰写状态。
4. 先看摘要，按现有规则解锁全文后阅读图表、章节和表格。可调字号、展开明细、下载正文，或使用浏览器“打印 / 保存 PDF”。
5. 点击报告追问。AI 读取该报告及原始计算依据，需要时补充工具调用；缺资料时请用户确认。可从会话回到原报告，原文不会被追问覆盖。
6. 也可直接进入“问 AI”，不必先生成报告。我的报告、历史问事以及原有删除/恢复边界沿用原逻辑。

## 原生 iOS 怎么用

使用前端仓库 `apps/ios-customer/DongFangApp.xcworkspace` 构建。首次检出后，在 `apps/ios-customer` 执行 `pod install`，再打开已提交的 workspace，选择自己的签名与手机。修改工程清单后再运行 `xcodegen generate` 并重新 `pod install`。默认 API 指向现有生产环境；此交付不自动更新手机上已安装的旧 App。

- AI问事默认进入「专题」，保留「问 AI」「我的报告」。十二份示例随 App 打包，与 H5 本次发布使用相同原创内容和计算图表；阅读示例无需登录或调用模型。
- 个人报告仍需登录。日期、时间使用原生选择器；农历日期输入文字并校验；合盘分别确认双方资料，面相手相使用系统照片选择器。
- 解锁后的报告显示四柱、五行数量、大运时间轴、宫位、卦爻、牌阵、配对信息和表格。长表格可横向滚动，宫位可展开，支持系统字号及深浅色。
- 「生成 PDF（含图表）」后可用系统分享面板保存或分享。导出使用已解锁快照，时间轴和宫位完整展开；当前 PDF 为原生渲染图片分页，正文分享另提供文字。
- 「围绕这份报告继续问事」返回原生问 AI 页，关联同一报告会话。会话提供返回报告、补充已确认资料、停止生成和工具记录。执行仍由生产 Harness 服务负责。
- 专题和报告使用原生 NavigationStack 与侧滑返回。移除装饰图形的循环动画，保留轻量按压反馈；“减少动态效果”设置下不做缩放或抽屉位移。

模拟器构建或自动化测试不代表真机签名、安装、支付、照片上传或所有专题真实模型质量已验收；请在手机上补验这些场景。未新增任何真实支付渠道或余额。

这是一套报告优先的产品结构，不等于天机阁全部算法、章节或交互已经完全一致。实际查看过 [天机阁八字](https://www.ai-tianji.com/bazi)、[紫微](https://www.ai-tianji.com/ziwei)的公开示例及其余八个板块表单。其余完整报告尚未取得；未复制对方正文、品牌或图片。

## Harness 与图表如何衔接

必要工具计算 → 存储计算依据 → Harness 按需读依据/补算 → 输出章节正文 → 校验 → 保存报告。图表由后端确定性转换器生成，AI 不能直接提供任意 HTML 或伪造图表数据。正文和图表都经过报告归属与解锁校验；原始工具证据不直接暴露在报告 API 中。

模型要求兼容 OpenAI 工具调用，继承模型目录的上下文和输出预算。1M 是配置上限，不要求每份报告都发送满 1M。面相手相没有可用视觉模型时显示未开放。工具停用、缺失或计算失败时不能用模型猜测替代。

管理台启用版本快照时，新技能须加入草稿、评测并发布到生效快照；只执行 SQL 不保证冻结版本包含新技能。工具可配置不代表真实服务可达，仍需运行真实模型报告验收。

- 临时 MySQL 8：基础 fixture、已有报告结构、工具目录和新迁移可执行，新迁移重复执行通过。生成、幂等、未解锁保护、其他用户拒绝读取、关联会话幂等与删除边界通过。
- 测试中解锁用隔离库的 points_paid 标记，仅验证权限，不代表微信/支付宝支付验证。模型为本机 SSE fixture，不代表 DeepSeek 真实报告质量。
- 390px 浏览器检查十二份示例的标题、图表/表格与页面宽度。Ego Lite 可读页面但截图超时，视觉检查改用内嵌浏览器。
