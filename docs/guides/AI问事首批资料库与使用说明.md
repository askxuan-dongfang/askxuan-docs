## 信众怎么用

进入 AI 问事 → 问 AI，用书名、章节和具体问题提问。例如：

- “请查《周易》乾卦九二原文，解释它在原文中的意思，并给出出处。”
- “根据香港天文台资料，相邻节气的太阳黄经相差多少度？”
- “根据 Waite 的 The Pictorial Key to the Tarot，愚者牌有哪些历史象征？”
- “比较《荀子·非相》的观点和现代外貌观察，哪些结论不能从照片推出？”

也可从十二专题填写资料生成报告，再围绕报告追问出处。Harness 会在需要文献时调用知识检索；计算命盘、起局、飞星等仍由对应算法工具负责。不是每次问答都强制查库，导入资料不会自动补齐缺失的算法或外部商业数据。

## 管理员怎么用

总管理台 → AI 问事工作台 → 能力中心 → 知识库，可看到十二个“AI问事 · 专题名”资料库，另保留原“问玄平台使用说明”库。可预览原文分块、验证搜索、停用文档或库。

现有十二专题库已加入发布智能体的知识范围。以后新增库，需要到“智能体开发”绑定，再保存草稿、质量评测、发布。新建文档需要解析完成并审核启用；重解析会撤销审核，必须重新核对。

## 来源、引用与范围

- 维基文库文本保留书名、来源页面、固定修订链接、贡献者与 CC BY-SA 4.0 说明。正文清除了站点导航，并按长度分段；保留繁体原文，不冒充影印校勘本。
- 当代官方资料仅保存少量自主撰写的事实摘要及链接；没有整站复制、付费课程、未经授权的现代译注或商业图册。
- 古籍属于历史文化材料，出现的确定性吉凶、身份或性别偏见并不代表平台认可。引用不能证明预测准确。
- 姓名重名统计、商标实时检索仍需对应数据接口；商标查询入口说明不是接通实时数据库。资料不能补造零重名或无冲突结论。
- 户型测量、朝向与玄空飞星需要实际比例尺、方位及元运数据；不能从古籍或图片自行补造测量值。
- 塔罗英文片段由模型解释为中文；本批未导入中文完整译本。竖排扫描件 OCR、专业校勘和各派论证不在本批验收范围。

来源原始页面包括 [维基文库《周易》](https://zh.wikisource.org/wiki/周易)、[英文维基文库 The Pictorial Key to the Tarot](https://en.wikisource.org/wiki/The_Pictorial_Key_to_the_Tarot)、[香港天文台历法资料](https://www.hko.gov.hk/tc/gts/time/24solarterms.htm)。完整逐文档登记见[来源目录](AI问事首批资料来源目录.md)；[下载可重建资料归档](../resources/AI问事首批资料-20260930.zip)（含 Markdown、来源及校验清单，不含密钥或用户数据）。

## 检索与验收机制

模型只可提交可选 query 检索词（1—400 字）；身份、知识库和审核范围由服务器绑定。多个知识库在 WeKnora 内统一检索排序，返回前再次检查启停和审核状态。引用包含出处、分块定位、修订与 SHA256；相关原文片段会发送给配置的回答模型。

验收覆盖十二专题定向检索、26 条 Harness 质量评测，以及《周易》、历法、塔罗三次用户真实问答。用户问答必须检查工具确实返回相应书籍的目标原文及出处，不能只凭回答包含关键词判定成功。最终结果见[发布验收记录](../reports/2026-09-30-AI问事首批知识资料发布.md)：12/12 定向检索、26/26 Harness 评测和三次用户问答通过。验收不代表所有历史释义或专业算法都已获准确性认证。
