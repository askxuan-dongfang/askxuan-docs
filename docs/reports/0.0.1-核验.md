# 产品 0.0.1 核验

产品版本：**0.0.1**。核验日期：2026-09-14。本页只维护当前结果；源码、本地测试、实际部署和真实业务验收分别记录。

## 当前范围

商城完整并入总管理台，寺院台独立保留。业务管理 Web 只有 `apps/web-platform-admin` 和 `apps/web-temple-admin` 两个构建工程。商城 17 个页面、8 个 API 适配器由总管理台拥有；旧 `/shop/*` 使用同次 admin 构建生成的 `legacy/shop/index.html`，无独立工程、运行依赖或发布组件。

此次同时修复刷新令牌身份域混淆和平台消息管理权限。旧版缺少身份域的刷新令牌需要重新登录；既有合法访问令牌按原期限生效。不涉及数据库、密钥或业务 API 路径迁移。

## 仍需独立验收的能力

- iOS 签名安装、App Store 发布及完整真机验收尚未完成；源码或模拟器构建不等于设备验收。
- APNs 生产凭据与真机通知、公网 TURN 和跨网络通话仍需独立放行，见[聊天需求](../../specs/024-chat-completeness-and-experience/README.md)。
- 模拟支付不能作为真实扣费、退款、提现和对账验收；真实短信、物流和直播需外部服务证据。
- DIY 两端已有确认收货；顾客 DIY 取消、退货退款入口尚未形成完整链路。
- iOS DIY 使用真实 SceneKit 3D，材料筛选尚无独立五行控件。
