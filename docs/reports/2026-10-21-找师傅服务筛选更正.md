## 更正范围

用户明确“需要提供服务，身份类型不要”。找师傅侧栏为“提供服务”“价格区间”，默认服务展开、价格折叠，保留顶部类型/宗派/地区和列表搜索。此要求更正前轮保留身份、移除服务的方案；[前轮验收](2026-10-20-DIY定稿发布与首页统一.md)保留原状。

| 项目 | 当前约定 |
| --- | --- |
| 服务目录 | 来自平台 `/service-types` 标准 S001–S013，不按当前结果生成；空结果仍保留全部选项 |
| 匹配 | 按 `serviceTags.serviceCode` 匹配；`nil`/空/`enabled` 兼容可用，其他显式状态不能命中 |
| 组合 | 与类型、宗派、地区、价格和关键词取交集；清除服务不清除其余条件 |
| 卡片摘要 | 优先显示所选服务，再补另一启用服务；未选按原顺序。起价、折扣、预约规则不变 |
| 状态 | H5 刷新保留有效条件，目录加载后清理未知服务编码；全部清除重置全部条件 |
| 旧链接 | `position`、`specialty` 不形成隐藏过滤；保留有效服务及其他现有参数 |
| 身份资料 | 保留身份字段；当前后端资料更新不开放 `position`，不新增随意自填身份能力 |
| 边界 | 后端、寺院目录、发布/付款/返现、成长和首页布局均未变更 |
