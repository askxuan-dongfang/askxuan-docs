# 头像与个人体验优化

用户认可局部样稿后，在现有经典配色、衬线标题和卡片层次上实现头像与个人页面优化。此次范围为信众个人中心、注册后资料补全、大师个人资料及工作台；保留已有订单、钱包、消息和服务履约流程。

## 已交付

- H5 与信众、大师 iOS 均改为照片选择、圆形裁剪、缩放和位置微调，输出 512×512 JPEG。保存资料时上传；取消不上传；上传完成而资料保存失败时复用上传结果，支持恢复默认头像。
- 信众注册成功后可设置头像、昵称或跳过；补全失败仍保留已注册账户。个人中心突出头像、钱包、服务进度和三类订单，消息只保留一个入口；未开放的成长记录弱化展示。
- 大师专长改为点选和自定义添加，认证身份只读。工作台优先展示待处理、履约和今日预约，再呈现常用功能、收入与评价；独立执业身份保留原有可用功能边界。
- 桌面与手机响应式布局、浅深色、弹层动效、键盘控制及减少动态效果继续使用现有设计体系。

## API 语义

- `PUT /api/v1/users/profile`：昵称、头像、性别、生日、地区、简介区分未传字段和明确空字符串。未传保留；头像、生日等可用空字符串清空；空昵称仍拒绝。
- `PUT /api/v1/admin/masters/profile`：头像、简介、定价说明支持明确清空；专长未传保留，空数组清空。
- `GET /api/v1/admin/masters/bookings`：新增可选 `date=YYYY-MM-DD`，由服务端过滤当天预约，并保留大师归属、状态和分页条件；非法日期拒绝。
- 图片复用 `POST /api/v1/files/upload` 的身份检查与图片字节类型校验。现网 bucket 未配置生命周期过期规则；本轮未调整数据库结构或运行配置。

## 截图反馈后的修正

用户反馈头像弹窗层层叠加、个人卡片比例松散、报告标题重复且内容像系统提示词。前一轮通过的功能与溢出检查并未覆盖这些实际观感问题，本轮以线上截图复现为起点补充修正。

| Before | After | Why |
| --- | --- | --- |
| 点头像同时打开资料编辑与大幅选图说明 | 直接打开系统文件选择，选图后只显示裁剪 | 减少步骤与叠加遮罩 |
| 裁剪 Esc 连带关闭资料窗口；重试可能重复上传 | Esc 返回原草稿，同一裁剪结果缓存上传 | 保留未保存内容和重试连续性 |
| 通用弹窗覆盖按钮边框和前景色 | 主次按钮保留自身样式 | 明确操作层级 |
| 个人卡片“＋”角标、重复身份标签、统计区留白过大 | 相机角标、精简标签、调整头像与统计比例 | 保留原有配色和卡片，改善密度 |
| 无右侧操作时标题偏右；桌面首条被导航遮挡 | 导航始终保留三列，内部滚动导航从自身顶部定位 | 真正居中并避免遮挡 |
| 报告大图重复、标题重复、展示生成请求 | 单一标题、紧凑列表、真实摘要、明确阅读状态 | 阅读内容优先，保留原解锁逻辑 |
