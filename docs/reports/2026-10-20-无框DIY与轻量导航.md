# 无框 DIY 与轻量导航实现、验收和发布记录

对应[标准产品原型](../product/无框DIY与轻量导航产品原型方案.md)、[可交互原型](../product/prototypes/diy-open-canvas-v2/index.html)。延续用户全端开发、测试、Git 合并与 ECS 部署授权；各子任务使用隔离工作树并行开发，统一复核与发布。

## 产品变更

- 手串直接位于页面上半部，无外围卡片；渲染区实际预留上下工具空间，撤销、重做不覆盖珠子。持续显示内围估算与偏短 / 合适 / 偏长，支持扩大预览。
- 材料分类竖排，增加正在使用筛选；选中珠子菜单可替换、复制、删除、换位。替换保留位置和唯一标识，库存按扣除原珠后计算，进入撤销历史。
- H5 与 iOS 共用八类原创配件网格、尺寸和连接参数，标准珠保留真实孔道。佛头为手串母珠造型；三通、莲花 / 葫芦 / 平安扣 / 木鱼 / 通用吊坠、流苏分别建模。未知吊坠不套用有特定含义的莲花造型。
- H5 WebGL 异常时提供可点选、删除、撤销的平面预览；恢复后可重新进入 3D。木、玉、金属材质保留各自参数，自定义材质优先。
- 寺院和师傅的五类信仰标签打开悬浮子项，没有展开动画和列表位移；选择、外点、Escape 关闭，外点不穿透进入详情，独立条件及 URL 保留。
- 商城顶部仅搜索和购物车同排；“我的”以成长值、积分、优惠券三列统计取代独立成长卡，游客保持登录引导。
- H5、服务方 H5、平台 / 商城 / 寺院 Web 的下拉与取消按钮减去常态装饰边框；保留聚焦、错误、禁用提示。macOS 管理门户沿用同一 Web 产物；原生系统下拉和取消沿用其轻量样式。

本轮不改成长等级、优惠规则、订单金额、库存接口或支付行为，不需要后端发布或数据库迁移。

## 原生验收

最终代码已通过客户 iOS 模拟器完整编译和 15 项单元检查（7 项编辑 XCTest、2 项材质 XCTest、3 项画布 Swift Testing、3 项几何 Swift Testing）。专用 iPhone 17 Pro / iOS 27 模拟器共 5 项 UI 用例通过：无框画布与长度反馈 / 已用筛选 / 替换 / 扩大预览，3D 点选 / 编辑 / 真实拖动换位与撤销，寺院和师傅悬浮筛选及返回，商城搜索与购物车同排，成长统计与详情。其中无框编辑、商城和成长三项在上一轮通过，另两项在最终重跑通过；分别保留原始结果，不声称一次运行全绿。

首轮共享模拟器记录单列保留：15 项单元检查通过，成长与商城界面用例通过；目录测试先误点屏外道教标签；iOS 27 对屏外 isHittable 也会抛异常，最终按视口几何判断后横向滚动并真实点击。DIY 用例期间出现未预期的额外珠子，复核录屏显示替换前后数量保持不变；已强化单颗前置断言，并切换专用模拟器复验，额外珠子未复现，不把首轮失败算作通过。专用模拟器冷启动首轮 AX 初始化超时，15 项单元通过而 UI 未启动；保持同一设备，初始化结束后重跑 UI。旧拖动用例原坐标落在空白处而触发旋转，已根据新渲染区域校准珠心，并先断言真实点选成功，再检查换位及撤销；产品代码未因测试修正改动。

## 证据与边界

- Web、原型与构建证据：本地 `artifacts/history/2026-10/diy-canvas-20261020/`。
- iOS 构建、测试和截图：本地 `artifacts/native/2026-10/diy-canvas-20261020/`。
- 八类配件为原创通用形态，非店铺 SKU 扫描；自定义实物资产可覆盖。SceneKit 的透明度是近似，不能称为与 Web 体积折射完全相同。
- 本轮原生交付为客户 iOS 源码及模拟器验证，ECS 更新不会自动更新已安装 App，也不代表 TestFlight / App Store 发布。法师 iOS 无对应客户页面，公共原生控件沿用既有样式且未在本轮重新运行验收。
- PWA、内嵌 Web 与 macOS 门户使用共享 Web 产物，本轮未分别启动其安装态 / 容器；服务方 H5 控件源码覆盖，未逐页验证所有业务流程。
- 早轮错误、超时与修正记录保留：后台校验初验错误地寻找表单红框，该页面实际使用提示消息；已按真实提示重新验证。Ego 单次点击超时后先读取页面状态再继续，没有绕过或新建空间。
