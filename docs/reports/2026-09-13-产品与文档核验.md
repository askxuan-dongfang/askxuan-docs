- 文档仓：`node scripts/audit-markdown-links.mjs`；检查 Markdown 本地路径存在性，不能替代外链可访问性或所有锚点检查。

## 本地清理结果

盘点 24 个 Git 根和 78 个目录候选后，精确清理 **35 处可重建目录，合计 2,455,732 KiB，约 2.34 GiB 的目录占用**。统计采用 `du` 分配空间，不能直接等同于 APFS 新增物理空闲空间。

| 清理项 | 规模 | 保留内容 |
| --- | ---: | --- |
| 旧副本 Node 依赖 | 约 1015.09 MiB | 源码、锁文件、主目录依赖与仍被鉴权夹具引用的依赖 |
| Web dist | 约 429.24 MiB | 原始 CI 发布包、manifest、回执和源码 |
| Xcode 缓存/中间产物 | 约 947.42 MiB | Logs、调试 Products、工程和资源 |

删除前重新检查 Git tracked 为 0、没有候选目录的活跃句柄、无嵌套 Git；删除后 **40 个明确登记的原始归档/回执 SHA256 全部保持一致**。数据库、OpenIM 数据与备份、配置、密钥、报告和 `.learnings` 保留；`.codegraph` 当时有活跃数据库句柄，保留约 267 MiB。

旧 worktree/clone 存在历史脚本绝对引用或原生依赖，保留源码父目录，不通过删除工作树破坏可追溯性。恢复方式见[本地项目目录与维护](../guides/本地项目目录与维护.md)。精确清单为 `cleanup-inventory.json`、`cleanup-review.md`、`cleanup-executed.json`，历史目录不改名。
