本轮补齐商品详情等级价、前台自动同步、跨设备一次性升级提示、定时规则版本与历史查询。产品与交互定义见[标准产品原型方案](../product/成长体系产品原型方案.md)、[五级业务规则](../product/五级成长体系方案.md)和[交互原型 P01—P14](../product/prototypes/growth-v1/index.html)。这是首期之后的补齐记录，不替代原有订单、地址、现金钱包验收。

## 实现范围

| 能力 | 实际行为 |
| --- | --- |
| 详情等级价 | 商品、咨询、寺院/师傅服务、DIY 材料、AI 报告按目录 ID、规格和数量向服务端请求；展示等级价、最优可用优惠和未参与原因。试算不下单、不预占库存或预算，以收银台最终确认快照为准。 |
| 自动同步 | H5/PWA/嵌入页、运营/寺院 Web、iOS 客户和服务者前台每 15 秒刷新；页面恢复、联网和支付成功触发刷新。正常在线目标不超过 30 秒；后台停止轮询，账号切换清空前一账号数据，草稿不被刷新覆盖。 |
| 有效期 | 详情报价 30 秒有效；数量/规格/账号变化立即丢弃旧值；离线、失败或超时不继续把旧优惠显示为有效报价。 |
| 升级提示 | 服务端原子领取，只提示最终升到的等级；多端并发仅一个领取成功，可关闭，不以降级打扰用户。 |

| 当前与历史 | 客户/服务者仅查看已生效版本；运营可查看待生效、已取消版本。已支付订单继续使用支付时快照，未来规则不回写历史。 |
| 覆盖端 | H5 客户/服务者、PWA与现有嵌入形式共用 H5；iOS 客户/服务者使用共享模型；运营、寺院与 macOS 管理门户使用同一 Web/API。未凭空增加 Android 或小程序产品。 |

## 证据边界
