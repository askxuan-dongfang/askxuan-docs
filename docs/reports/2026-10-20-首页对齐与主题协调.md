## 需求与范围

用户反馈浅深色首页不协调，核心入口与分组、信仰内容边线不齐。四个核心入口保持 2×2 和原有纹样，移除块状背景，统一字体层级及各区间距；信仰与心愿去掉竖线和徽标小框。

| 部位 | 本轮约定 |
| --- | --- |
| 公共边线 | 核心、分组标题、信仰、心愿共用页面左右内容边线，各项水平内距为 0 |
| 核心入口 | 最小高 104px，上下内距 16px；32px 图标、18px 标题、内部间距 10px；行距 12px、列距 24px；透明背景和右侧低对比纹样 |
| 分组 | 标题 20px，标题下 12px，分组间 28px |
| 信仰 | 五类完整；手机 2+2+全宽，最小高 84px、上下内距 14px；16px 标题、12px 说明，与裸字间距 8px；裸字 24px、透明度 0.65；轻横线，无竖分隔 |
| 心愿 | 手机三列、最小高 56px、列距 12px；22px 图标+8px 间隔+14px 文案，左对齐，无竖框 |
| 主题与宽屏 | 使用现有 H5 浅深主题变量，深色背景 `#1C1210`；几何尺寸不随主题变化。H5 在 1024px 断点显示五列信仰、六列心愿；核心仍两列 |
| 大字与窄屏 | 保留字号层级，内容可增高/换行，心愿按空间重排；无裁切或横溢出 |

本轮不改变定稿发布、付款、返现、成长规则或搜索合同。其结果和剩余限制继续见[前轮验收记录](2026-10-20-DIY定稿发布与首页统一.md)，旧截图不能充当新增布局的验收。
