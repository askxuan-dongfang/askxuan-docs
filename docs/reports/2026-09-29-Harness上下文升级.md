## 能力边界

1. 上下文按 UTF-8 字节保守估算，图片和工具另留余量；不是精确分词计费。供应商 usage 才是实际用量依据。
2. 旧轮次压缩为有限用户问题摘录，不是语义总结或跨会话长期记忆。
3. 未向外部模型发送满 1M Token 压力请求，也未强制生成 8K/16K 字数；验证的是额度生效、模型容量和应用预算装配。
4. 本次新增使用量与停止按钮为 H5 交互，iOS 共享后端新额度，但未更新原生 UI 或进行真机验收。
5. 取消注册表目前为单 AI 进程状态；未来多实例部署需增加跨进程取消路由。
6. 未重放真实个人报告，未测试全部五类工具；初次专题报告仍走原报告流程，追问走 Harness。
