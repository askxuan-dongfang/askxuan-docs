# 轻量控件、悬浮筛选与个人商城入口

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-10-19


## Overview

用户于 2026-10-20 追加：全局下拉和取消按钮减去常态边框；寺院 / 师傅子派别悬浮、不挤动其他筛选、无展开动画；商城移除重复标题，购物车与搜索同排；我的成长移入积分左侧。与 DIY 优化一并全端验证发布。

## Design

- 下拉常态以底色、文字、箭头识别，取消按钮使用轻量文字层级。聚焦、错误、禁用状态可辨；仅取消装饰描边，不清空全局边界颜色。
- 点击父类型打开其下方悬浮子项，不占布局空间。选择、外点或 Escape 关闭，按键可访问，关闭返回触发项；父子 URL 与独立条件保留规则不变。
- 原生目录采用同等不挤动的覆盖层；移除展开与筛选选择动画。长列表可滚动，横向和窄屏不溢出。
- 商城顶部只保留搜索和购物车，数量与导航行为不变；iOS 同步，服务端搜索与订单契约不变。
- 我的账户统计依次为成长值、积分、优惠券；三项同高等宽，成长入口显示实际成长值并进入已有成长详情。移除独立我的成长卡，游客保留登录引导、不显示虚假余额。
