# 演示媒体、服务心愿继承与分页闭环

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-10-14

## Overview

补齐 72 个演示寺院和 144 位演示师傅的图片、心愿发现路径以及 H5 分页。旧补数脚本只写提供者与服务，漏写心愿映射；当前 H5 固定只请求 30 条。

## Design

- 七个心愿入口不变。标准服务使用统一默认规则，提供者服务默认继承；手动配置优先，明确空选必须保持排除，可恢复继承。存量非空配置迁移为手动配置，不覆盖运营选择。
- 聚合时仅展示标准服务目录内、公开寺院 / 师傅已开放的服务。寺院师傅取寺院与个人服务交集，展示寺院费与执行费之和。稳定排序包含服务编码，避免同一师傅多服务的分页顺序不确定。
- H5 按页加载，保留已加载内容，重复点击不并发追加，失败可重试；切换心愿取消旧结果，服务复合键去重但不合并同师傅的不同服务。
- 图片采用 AI 生成的共享演示素材库，按文化类别配对封面、头像与相册；明确非实拍、非本人肖像。所有新资料具有可访问媒体，API 与 H5 使用同一资源路径。身份守卫和运营上传优先，避免替换真实资料。
- 备份后执行幂等迁移；使用既有分支与标准发布器。分别验证源码测试、数据库结果、Git 推送、部署文件和浏览器。
