# 平台免费活动与实物领奖

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-09-09


## 产品设计

积分商城提供确定兑换权益；免费转盘与大奖池由平台预算承担奖品和履约成本；功德值独立记录成长，不参与支付、兑换或概率加权。活动不收现金、不扣积分、无充值购买机会，不按商品价值折算积分池。

- 大奖池：每用户每期一个有效码，参与记录不可删除。截止时间固定，满额仅停止参与，不提前开奖；到期即抽取 min(奖品数量, 有效参与人数) 个不同中奖码。N 个码抽 K 名，每码概率 min(K,N)/N；100 抽 1 为 1%。无人参与时正常结束并公告。
- 转盘：每用户每期免费一次，预设总名额及实物奖品数量；从剩余名额中均匀随机抽取，当前概率为剩余奖品/剩余名额，界面明确披露。结果在服务端确定后播放动画；网络重试返回同一码同一结果。到期关闭，剩余奖品不强行发放。
- 平台新建草稿，配置奖品名称/图片/描述、奖品单价参考值、数量、独立预算、总名额、开始/截止时间和规则。预算须覆盖奖品参考总值；预算是运营配置，非现金划拨凭证。发布后冻结规则和库存；仅无参与时允许取消并说明原因。
- 公告保留开奖时间、有效人数、算法版本、参与码摘要及中奖码。公开接口不暴露用户身份或地址。无外部公证或第三方验证的声明。
- 中奖生成独立奖品订单：待填写地址 → 待发货 → 已发货 → 已完成；用户提交地址、确认收货，平台运营填写物流，所有转换留痕。地址限订单本人和平台超管可见。

## 实现范围

营销服务独立活动/参与/奖品订单/操作审计表；数据库唯一键、事务行锁、crypto/rand 无偏随机、定时补偿开奖。H5 与 iOS 免费活动中心、详情、参与记录、公告与领奖；平台管理台活动和履约。H5 搜索仅首页，退出登录归入双方“我的”。

## 运营边界

上线不自动发布没有真实备货和预算的活动。平台超管可创建草稿、确认奖品与运费预算、设定截止时间后发布；测试草稿不形成实物发奖承诺。功德值继续沿用独立成长定位，现有成长记录接口未开放，本次不生成虚假成长值。
