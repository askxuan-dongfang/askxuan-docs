# DIY 定稿发布与首页视觉统一

> **Status**: ⏳ In progress · **Priority**: High · **Created**: 2026-10-20 · **Tags**: product, diy, cross-platform

## Overview

用户确认：只有本人同款订单已付款，且款式、用料和价格确认后，设计才能发布并作为后续同款返现来源。同时恢复 DIY 小幅珠环装饰，统一首页无外框、字体和图标，精简师傅筛选，将成长规则并入等级权益。

承接 [055 直接拖拽](../055-diy-direct-drag/README.md)，新合同替代该版“保存后自动下架”；历史实现与验收记录保留。详见[产品方案](../../docs/product/DIY定稿发布与首页统一产品原型方案.md)、[可操作原型](../../docs/product/prototypes/diy-publication-v4/index.html)及[验收记录](../../docs/reports/2026-10-20-DIY定稿发布与首页统一.md)。

## Design

- 复用真实付款与审核进入制作节点；模拟支付、待确认、取消、售后、退款、不匹配配方均不能发布。服务端资格是唯一依据，未知状态关闭发布。
- 公开定稿冻结设计、确认材料价与来源版本。保存草稿不改旧定稿，下架独立；新款重新付款确认后才能发布新定稿。
- 按珠子顺序、材料规格、绳线、手围、松量及订单价格明细核对；不能只比较版本号或客户端价格。
- 同款多级复制保留原定稿受益人；改款并重新付款确认才形成新款。比例、等待期、净材料费和退款冲回沿用既有规则。
- 首页四个纹样入口固定两列，32px 图标、18px 标题，透明背景、最小高 104px；共用页面边线、24px 列距。分组标题 20px，分组间 28px、标题下 12px。信仰 16/12px、最小高 84px，心愿 22px 图标/14px 字左对齐，无竖线和徽标小框；浅深色同一布局，宽屏保留五信仰/六心愿。
- 师傅移除擅长/服务筛选与演示副标题，旧查询参数不形成隐藏筛选，相关内容仍可搜索。保留身份和价格，标题单行。
- DIY 恢复绿金手串与“一珠 / 一心意”，置于紧凑顶区，不恢复旧大幅首屏。
- 成长保留档案、任务、明细、权益四入口；规则与历史版本放权益下方，旧 rules 深链跳权益并展开定位。业务数值不改。
