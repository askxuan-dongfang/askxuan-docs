# AI 发现入口与可核验互动技能

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-09-21


## 目标
有历史会话的用户仍能发现其他主题；将报告和私密手记作为常驻入口。首期提供姓名灵感和两难梳理两种不同的完整体验。

## 设计
- H5 保留五个主 Tab，AI 内部为发现、问事、手记。默认发现，会话深链接直达；切换发现不丢聊天草稿。
- 姓名灵感采用版本化词库：16 字、12 组候选、3 种风格，用途、姓氏、避用字均参与校验。显示字义来源、常用读音和编辑联想，收藏比较；不伪造古籍原句。
- 两难梳理采用 2–6 个用户填写的因素，重要性和满足度均 0–5。分数 = 加权满足度 / (权重和 × 5) × 100；硬约束优先。结果不是成功概率。
- 两种体验是确定性技能，不消耗模型额度或积分；通用聊天和原专题继续使用实际模型与工具。
- 结果由服务端执行并重算后保存，客户端不能提交任意结果。手记按信众身份和用户 ID 隔离；幂等键防重复保存，相同键不同输入返回冲突；可删除。
- 输入草稿只存当前浏览器会话并按用户 ID 分隔，不作为永久手记；私密手记服务端持久化。
- 原工具被禁用、失败、空结果时，不能静默生成“已计算”解读。内部提示与用户显示文案分离。
- 150–160ms 按压反馈，减少动态效果时移除缩放；无强制等待、自动演出或虚假进度。
