# iOS 活动体验补齐与积分入口精简

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-09-10


## 交付范围

用户反馈积分页同时存在两个活动分类入口和“好礼与体验”的同类商品入口。浏览器实际操作确认，上方进入活动分类，下方直接进入同一批示例，层级重复。

H5 与 iOS 统一保留“积分转盘”“大奖池”两个分类入口，以及参与记录、我的奖品两个记录入口。具体奖品、正式活动和体验示例只出现在进入后的活动列表；积分明细、商城和兑换记录继续在积分页。

## iOS 实现

- 新增独立原生活动模块，抽离原个人页中活动代码。积分入口采用动态礼品插画卡片，列表展示香囊转盘与香珠手串奖池示例。
- 本设备按账号保存 100 演示积分，转盘 10 分、奖池 20 分；重复参与返回原码、重置开启新轮、三天截止。示例明确不扣真实积分、不发实物，且不写生产活动或物流 API。
- 八格转盘、七圈旋转后减速、奖池参与码生成与开奖揭晓、结果弹窗与中奖纸屑、实时倒计时、浮动插画、固定参与按钮及动画区域自动定位。系统减少动态效果时关闭动画等待。
- 示例参与记录、开奖公告、演示领取、待发货、模拟发货、模拟收货全流程持久化。正式活动保留服务器积分确认、扣分、结果、公告和实际领奖接口。
- 动作离开页面时取消动画等待，已在服务器成功的参与不会回滚或重新扣分；再次打开从服务器读取结果。
