# DIY 无框画布、佩戴反馈与配件模型

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-10-19


## Overview

用户于 2026-10-20 授权将截图评审落地。手机上半部直接显示手串，去掉工作台及预览的外围卡片；工具避让、佩戴长度可见，随后统一材质与配件模型。H5 / PWA / 内嵌 Web 与 iOS 使用同一设计数据、材质参数和模型规格。

## Design

- 无框统一底色；右下撤销重做、上方工具留出实际操作区，画布不会被覆盖。窄屏保证选材与底部金额操作可达。
- 顶部显示偏短 / 合适 / 偏长及估算内围，手围入口显示详细差额。保持毫米单位、设计顺序和草稿恢复。
- 标准珠参数化，三通、佛头、吊坠、流苏按品类建模；孔道和连接位置明确，Web 与原生共用模型资产与校准参数。
- 保留自定义材质优先级、按需渲染、减弱动态效果；精简后的异常提示不得指向已移除的列表。
- 材料名称最多两行，已用筛选帮助回找，选中珠子编辑入口可发现。
