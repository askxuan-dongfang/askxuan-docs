# 统一运营管理后台

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-09-09


## 目标与边界

将商城管理台所有已实现功能完整迁入平台总管理台，统一登录、导航和交互。保留原平台功能、角色权限及现金/积分/活动奖品账目边界；寺院管理台与法师、信众客户端保持独立。历史原型中尚未实现的能力不以本次迁移宣称完成。

## 实现

- 商城 17 个业务路由迁至 `/admin/commerce/*`，原平台 28 个业务路由全部保留。业务页面及 API 逐文件迁移，共享 Element Plus、组件、主题与统一认证客户端。
- 主导航分商城与权益、DIY 与加持服务、履约与售后、机构与人员、审核中心、财务中心、增长运营、系统治理。原商城工作台与平台商城运营总览分别保留。
- `/shop/*` 仅兼容跳转，同源转至对应新页面，保留详情 ID、搜索参数、hash 与登录后的目标地址。旧商城会话仅在统一会话缺失时迁移；已有统一账号优先；退出清理两套会话，避免旧链接恢复登录。
- `shop_admin` 可操作原商城全部功能，不能进入平台机构、账户、财务或活动奖品预算。`platform_super` 拥有两端全部操作；`platform_service` 保留原平台页面范围，不能借父路由绕过奖品页面限制。每一级路由单独检查，菜单使用同一判定；服务端网关和奖品服务继续独立校验。
- 积分活动在增长运营中管理；积分商品、订单与统计在商城与权益中管理；功德值继续独立成长定位。

## 功能保全清单

| 原商城功能 | 统一后台路径 | 保留操作 |
|---|---|---|
| 工作台 | `/admin/commerce/dashboard` | 销售与订单统计、趋势、待办与最近订单 |
| 商品列表/编辑 | `/admin/commerce/products`、`products/edit/:id?` | 搜索筛选、分页、新建编辑、上下架、图片、价格和库存 |
| 分类 | `/admin/commerce/categories` | 新建、编辑、删除、层级与排序 |
| DIY 材料/编辑 | `/admin/commerce/materials`、`materials/edit/:id?` | 分类、规格 SKU、价格库存、图片、上下架 |
| 加持服务/编辑 | `/admin/commerce/services`、`services/edit/:id?` | 新建编辑、寺院关联、价格和状态 |
| 现金订单/详情 | `/admin/commerce/orders`、`orders/:id` | 查询筛选、商品明细、物流、发货 |
| DIY 订单/详情 | `/admin/commerce/diy-orders`、`diy-orders/:id` | 材料快照、加持状态、发货与退款状态 |
| 物流 | `/admin/commerce/logistics` | 快递公司、运费模板、启停、物流查询与批量同步 |
| 退货/详情 | `/admin/commerce/returns`、`returns/:id` | 审核通过/拒绝、收件说明、收货、退款 |
| 经营报表 | `/admin/commerce/reports` | 日期范围、销售趋势、商品排名、订单与退款指标 |
| 积分商城 | `/admin/commerce/points-mall` | 独立商品、分类、积分价格、库存、上下架、搜索、兑换订单发货/取消、积分报表 |

原平台所有模块继续保留：平台总览、商城运营总览、寺院列表/审核/详情、法师列表/审核/创建/详情、用户列表/详情、评价/素材/举报审核、财务总览/寺院结算/法师结算/对账、Banner/活动/优惠券/活动奖品、首页分类/角色/账号/字典/日志/备份。
