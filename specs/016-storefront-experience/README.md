# 商城选购与统一管理体验

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-09-10


## 目标与范围

商城沿用全产品的暖棕底色、金色点缀、宋体标题和清晰的金额数字，按浏览、筛选、选规格、加入购物车的顺序组织。管理入口仍位于统一平台的「商城与权益」，保留商品、分类、SKU、订单、售后、物流、积分及活动的原有接口和权限。

## 顾客端

- H5 `/c/shop`：主视觉、订单和购物车、积分商城与 DIY 入口；分类取后台真实数据，按排序值和 ID 升序展开。
- 商品支持关键词、分类、最新商品、价格升降序、仅有货；参数保存在 URL，返回详情前的筛选状态可恢复。
- 服务端分页，显示总数；继续加载失败可重试相同页。忽略过期请求，防止快速筛选后旧结果覆盖新结果。
- 商品卡片展示主图、分类、真实标签、两位小数价格及售罄状态；图片失败显示明确占位，不用无关商品图片代替。
- 详情：图片缩略图、完整标签、规格库存、数量步进和购物车反馈。详情请求成功前禁止购买，下架、无货或请求失败也禁止操作。
- iOS 同步主视觉、后台分类、服务端排序、库存筛选、分页重试和价格精度。提交搜索前的输入不影响正在浏览的分页。
- 装饰动画遵循系统减少动态效果偏好；保留订单、定制、积分商城及既有结算链路。

## 管理平台

- `/admin/commerce/products` 保留管理表格与上下架、删除操作，新增顾客视角卡片和本页展示检查。
- `/admin/commerce/products/edit/:id?` 分为商品身份、图文、价格履约三段；名称、分类、标签、主图、介绍与价格实时预览。
- 标签输入支持新增和删除；首标签用于列表，全部标签用于详情。参考价高于售价才显示划线价。
- 新商品保存草稿；已有商品加载失败会禁用保存，避免默认空值覆盖数据。配送模板及未涉及字段继续保留。
- 分类管理展示商城导航预览，维护名称、排序与层级；不引入新的管理平台。
- 网关返回凭证无效或已过期（40102/40103）时跳转登录，避免继续显示失败的管理页面。

## 接口与兼容

`GET /api/v1/products` 新增可选参数：`sort=newest|price_asc|price_desc`、`inStock=true`。不传参数保持旧客户端的最新商品行为。仅查询已上架商品；库存过滤同时作用于总数与明细，排序发生在分页之前，使用 ID 作为同价稳定排序键。非法排序返回参数错误；排序表达式不接受用户输入拼接。页码至少 1，每页超出 1–100 时使用 20。

无数据库迁移，无积分、商品库存、订单数据重置。价格筛选只影响浏览顺序；订单价格与库存仍由原有服务端结算校验。
