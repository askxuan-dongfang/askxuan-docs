# AI 问事会话管理与七专题体验升级

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-09-10


## 目标

历史问事提供可发现的删除入口；专题解读从长表单改为有主题、有引导的探索流程。延续 [专题报告](../005-ai-topic-reports/README.md) 的真实生成、摘要预览、积分解锁、报告追问与权限边界。

## 会话删除

- H5 历史抽屉与 iOS 历史列表，每行独立选择与删除按钮；删除前明确确认，失败保留原会话并允许重试。
- 删除当前会话清空消息、草稿、图片与选中状态；删除其他会话保留当前内容。切换/删除后旧的消息请求和流事件不能覆盖当前页面。
- `DELETE /api/v1/ai/sessions/:id` 继续使用现有 `closed` 状态作逻辑删除，同一用户重复请求幂等。用户身份由可信网关注入，不能删除其他用户的会话。
- 客户端历史接口仅列出 `active`；已删除会话的详情、消息、发送、重试、流式响应与工具追踪均不可访问。内部审计记录保留，不等同于数据库物理清除。
- 删除报告追问会话保留已购报告；再次从报告追问时，事务创建新的会话而非恢复已删除会话。

## 七专题设计

H5 统一使用 C 端既有的深棕背景、暖金强调和朱砂主按钮。专题页复用全局设计变量、48px 导航、768px 最大页面宽度与响应式边距；表单、阅读卡片、生成状态、报告列表及确认弹窗保持同一套表面层级、字体和控件样式。七个专题通过图形与少量装饰色区分，交互按钮和内容标题使用统一品牌色，避免进入专题时像切换到另一个产品。


| 专题 | 视觉主题 | 问题引导方向 |
| --- | --- | --- |
| 八字命理 | 暖赭色、日轮与四柱纹样 | 个性优势、职业方向、生活节奏 |
| 紫微斗数 | 星紫色、星点连线与轨道 | 发展重点、事业关系、转变 |
| 姻缘合盘 | 玫瑰色、双环交叠 | 相处、沟通、彼此需求 |
| 风水布局 | 苔绿色、屋舍与植物 | 采光、动线、工作休息空间 |
| 六爻占卜 | 湖蓝色、爻线纹样 | 影响因素、选择、行动 |

| 塔罗指引 | 雾紫色、卡片与月相 | 情绪、价值关注、自我照顾 |

图形为装饰，不代表已完成用户排盘或抽牌。H5 SVG 与 iOS Canvas 提供缓慢漂浮、轨道旋转、星点呼吸；响应系统“减少动态效果”，不使用虚构进度百分比。

## 交互流程

- 专题入口：双列主题卡与「我的报告」，各专题独立主题图形和引导语。
- 填写：先填后台 schema 要求的资料，再描述问题；可返回修改且保留内容，问题灵感仅填入文本，生成需用户主动提交。
- 生成：免费摘要、不扣分；等待状态可离开后从报告列表回看，失败可免费重试，超时支持现有恢复流程。
- 请求重试：保留同一次生成的 requestKey 和原始资料，网络不确定时防止重复生成；提交后不继续修改同一请求载荷。
- 阅读：主题报告头、摘要、完整章节预览；解锁确认显示实际价格与扣分前后余额。余额不足保留摘要，余额未知需重新获取。
- 已购：章节跳转、字号切换、保存/分享、带报告上下文继续问事；生成文本按安全文本渲染，不执行返回的 HTML。
- H5 保持问事父页面挂载，进入/退出专题不丢失聊天草稿；原有图片问事、技能选择、流式回答与重试保留。
