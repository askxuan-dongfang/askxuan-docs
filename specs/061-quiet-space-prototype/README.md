# 静心小院本地多人原型

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-11-05 · **Tags**: h5, quiet, prototype, multiplayer


## 目的与范围

在H5首页增加静心入口，提供可立即体验的原创小院、人物走动/入座、合掌/礼拜、静坐、木鱼、念珠、声音与本设备记录。用户授权先看本地一版，没有授权发布；交付边界是本地原型，不是生产多人验收。

## 实现

- 首页在找寺庙/找师傅后增加静心卡，进入懒加载的 /c/quiet；首页不创建Canvas。
- 现有React、TypeScript、Three.js/R3F/Drei生成原创院落与人物，无新增前端运行依赖。手机正面镜头、桌面斜视；WebGL失败保留轻量练习。
- Go独立本地游客房，仅127.0.0.1:8096，WebSocket通过Vite同源代理；20人为代码上限。服务端维护身份、人物、动作和6座位互斥，校验Origin、大小、频率、坐标与速度；内存状态，离线释放。
- 客户端断线清除远端并允许独自练习，手动重连；pagehide关闭旧文档连接。声音/计时/移动后台暂停，回前台不擅自启声或恢复计时。
- Web Audio合成木鱼、拨珠、钟与轻风，无外部素材。计数不兑换成长值，自动木鱼不计手敲；上次记录只在本设备保存并可清除。
