# DIY 材质质感与页面精简

## 目标

修复制作页尺寸弹层偏移、撤销含义不明和统一塑料高光。保留经典配色、首页原有构图及既有编辑、保存、定制流程，只删除用户点名的小字；H5 与原生 iOS 使用同一素材与表面配置。

## 实现约束

- 首页保留“把喜欢，串在一起”的主标题、大幅绿金手串装饰、双层边框、原按钮、卡片、搜索和作品导航；仅删除英文眉题、指定的两行说明、旧 2D / 3D 说明、列表故事句和空状态说明。CSS 布局保持原样，不改成紧凑入口。
- 撤销、重做使用规范图标与文字；尺寸弹层适配窄屏、横屏与桌面。iOS 尺寸设置直接展示手围和松量。
- 共享资源包括 8 张实拍参考、木皮 PBR 和摄影棚 HDRI，按 20 类表面配置当前 45 款材料。材质来源、授权、裁切调色说明与 SHA-256 随资源发布。
- 缩略图与珠体共用纹理。珠体有贯穿孔，木材、种子、玉石、水晶和金属采用不同粗糙度、涂层与透光参数。
- H5 物理透射与 SceneKit 的透明近似分别实现；iOS 不宣称等同体积折射。参考照片不是店铺 SKU 实拍，程序纹理与雕刻外形示意的边界必须保留。
- 素材在 frontend 管理，H5 通过固定版本同步；发布校验资源清单、字节与源文件哈希。保留用户自定义素材优先级。
