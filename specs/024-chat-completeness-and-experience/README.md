# 真人聊天完整性与双端体验

> **Status**: ⏳ In progress · **Priority**: Medium · **Created**: 2026-09-12

## Overview

补齐真人付费咨询与预约聊天：可靠文字收发、已读/未读、历史分页、私有附件、音视频通话、真实 iOS 通知，并统一四端交互。

## Design

- 业务数据库是消息权威来源。写入后确认“已发送”；OpenIM 通知使用可重试 outbox。只允许原发送方使用同一幂等 ID 重试。
- 每个参与人的读取游标只增不减；客户端显式提交实际加载并阅读的位置。服务端由游标统计未读和对方已读。
- 使用消息 ID 游标分页，避免新消息到达时历史页漂移。对话详情直接按 ID 授权查询。
- 附件使用受 JWT 和会话成员保护的私有存储，20 MB/文件，上传前预览、语音先试听，未发送附件仅所有者可读。
- 通话采用 WebRTC、业务鉴权信令和短期 TURN 凭证；只在用户接听后请求音视频设备，结束/超时释放设备。
- H5 用户/师傅共用聊天页面。iOS 保留原生列表、系统提醒、文件分享，通过受限 WKWebView 复用聊天详情；凭据不出现在 URL，不允许外部页面导航或访问桥接。
- APNs 使用挂载的 .p8 配置和真实系统设备令牌；缺少凭据时不宣称推送可用。通知不直接显示咨询正文。
