# 五级成长体系：成长值与等级规则

> 设计基线：2026-10-19，方案版本 `growth-v1`。设计已整理，功能待实现；下列数字是首期产品参数，不代表线上已生效或经过营收实验验证。

## 定位与等级

用户侧统一称“成长值、成长等级、成长记录”，替换原“功德值”占位。成长值体现平台参与和使用积累，不评价宗教修为或人格；不能购买、消耗、转赠、提现或兑换积分。人民币钱包、消费积分、创作收益继续各自记账。等级不改变抽奖概率、积分兑换价或服务效果。

| 等级编码 | 简体名称 / 繁体名称 | 有效累计成长值 | 距下级需要 |
| --- | --- | ---: | ---: |
| L1 | 初识 / 初識 | 0–199 | 200 − 当前值 |
| L2 | 同行 / 同行 | 200–999 | 1,000 − 当前值 |
| L3 | 笃行 / 篤行 | 1,000–2,999 | 3,000 − 当前值 |
| L4 | 致远 / 致遠 | 3,000–7,999 | 8,000 − 当前值 |
| L5 | 恒久 / 恆久 | ≥ 8,000 | 已达最高等级，继续记录 |

等级长期有效，不设年费、保级消费、自然过期或连续签到惩罚。有效累计值 = 已入账增加 − 已入账冲回；退款和作弊撤销可能降级。待入账不计升级。合法数据始终非负，冲回不得超过原事件尚未冲回部分；账本异常进入核对，不能用截零掩盖差错。

## 获取规则

所有次数按账号合并各端计算，业务日/月固定为 Asia/Shanghai 自然日/月；设备时区不改变额度。正向事件需具备服务端业务凭据；打开页面、登录、点赞、转发、邀请注册不发成长值。

| 来源 | 首期数量与上限 | 有效条件与入账 |
| --- | --- | --- |
| 完善基础资料 | +20，每账号终身一次 | 昵称及头像已保存，可用系统头像；不要求地址、生日、宗教、证件；校验成功即入账 |
| 完成精选学习内容 | +3，每日一次 | 运营标注的内容；图文前台有效阅读累计 ≥60 秒并到达末段，音视频实际播放 ≥80%；同内容终身一次，服务端校验后入账 |
| 保存当天成长记录 | +2，每日一次 | 保存一项当日行动记录，文字补充自愿；私密默认，不强制公开；重复保存/换端不重复奖励 |
| 完成官方活动 | +20，每月最多两次 | 唯一报名与签到/完成凭据，运营确认；同活动一次；仅活动页浏览不计，当前未接核销的活动不得发放 |
| 如实评价已完成订单 | +5，每订单一次、每月最多四次 | 星级高低同奖，无评价公开长度门槛；交易观察期结束且评价通过内容规范后入账；纯积分、模拟和取消订单不计 |
| 符合范围的实际消费 | 每实付 ¥1 得 1 成长值 | 按原始结算单的合格净实付分数总和除以 100 向下取整；不足 ¥1 不跨单累计；无倍增、无金额封顶 |

周期性非交易来源合计每月最多 **200**，包含评价；资料首次 +20 独立，不占月额度。按服务端确认时间所属日/月和确认顺序计次、占额度；实际奖励取基础数量与剩余额度较小者，满额后只记录完成，任务页先显示本次可得数量。撤销不回补额度或重排已完成任务，同一任务不可反复领。删除私密成长记录不扣分，已确认作弊除外；账本仅留必要凭据，不保留被删正文。

消费基数只含商品、DIY 材料及制作费、固定服务费、即时咨询、人民币解锁 AI 报告的实际净支付。未参加等级折扣的正常付费项目仍可积累成长值。真实人民币钱包扣款视为实际支付；模拟支付/余额、体验单、赠金、积分兑换或解锁、充值、运费、随喜、捐赠、保证金、创作收益入账本身均不计。优惠券与平台补贴部分不算用户实付。不能按支付总额直接发放，混合费用必须先拆项。

## 到账、升级与退款

1. 付款后生成“预计获得”，只作估算。商城/DIY 确认收货、预约由客户确认回执、咨询服务期结束、报告成功解锁，分别形成完成时点；接单、发货或报告生成失败不算完成。
2. 完成满 **7×24 小时**且无进行中售后，按净实付入账。该观察期不替代各业务售后期限。处理中显示“待入账”，并列预计时间和暂停原因。
3. 部分退款完成后按合格费用剩余净实付重算；整单退款归零。入账前改预计值；入账后写差额冲回。退款失败不扣，处理中暂停该单发放；退款成功不依赖用户再打开页面。
4. 订单评价奖励仅在整单取消/全退、评价因作弊撤销时冲回；正常部分退款且订单仍有效保留。增长规则按原事件版本计算，不对多次退款分别取整。
5. 入账/冲回与等级更新同一事务生效，允许跨级；新权益用于此后创建的结算单。促成升级的原订单不追补折扣，已经支付的其他订单不因降级追补差价。
6. 记录提供来源、正负数量、订单/活动、业务发生与入账时间、状态、原因、规则版本。重复支付/完成/退款通知不重复记账，乱序退款先到亦能按事实重算。

例：合格实付 ¥199.99 → 199；先退 ¥0.99 后仍为 199，再退 ¥0.01 后剩 ¥198.99 → 198，只冲回 1。原有 190，入账 30 后达 220 升 L2；以后该单全退则回到 190/L1，已支付订单不补差价。

## 可达性与历史迁移

- 每月达到非交易上限 200、不消费：第 1/5/15/40 个完整月分别达 L2/L3/L4/L5。这是上限演算，不承诺仅登录即可达到。
- 资料 +20，每月 20 天各完成学习和记录（100），再完成 1 次活动（20）：两个月累计 260 达 L2。
- 单次真实合格净消费 ¥1,000，完成观察期后从 0 达 L3；¥8,000 可直达 L5。等级表达使用积累，不将其宣传为精神成就。
- 首期从统一生效时点开始积累，历史订单、旧占位“—”、模拟数字不回填；存量用户也可领取一次资料任务奖励。若发现真实旧成长账本，先核对独立迁移，不默认为余额或转换为现金。
- 首期阈值长期保留。后续规则版本只改新事件；不得后台静默提高门槛使存量用户降级，需另行制定并公告迁移方案。
