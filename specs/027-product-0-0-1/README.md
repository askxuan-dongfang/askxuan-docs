# 问玄东方 0.0.1 当前产品基线

> **Status**: ✅ Complete · **Priority**: High · **Created**: 2026-09-12 · **Tags**: release, baseline

## Overview

统一当前源码、客户端版本、品牌资产和四册手册，移除已被当前产品替代的历史工作区内容，建立可核验的0.0.1版本基线。

## 当前产品范围

H5 信众/法师、两个原生 iOS、统一运营后台、寺院后台与商城兼容入口；后端为 19 个业务服务与网关。品牌源位于前端 packages/brand，产品正文位于当前四册手册。

0.0.1 表示此次统一的产品基线，保留现有能力限制与待验收项目。iOS 构建号保持连续；第三方依赖版本、API 路径版本和数据库迁移不随产品版本重置。

## 实施

- [x] 对外版本、仓库 VERSION 和四册文档统一为 0.0.1。
- [x] 当前源码吸收已应用的品牌 manifest 配置修复。
- [x] 移除旧品牌、原型、备用 Expo、旧任务工作树与历史文档，迁出仍必要的部署配置。

## 范围说明

移除工作区中的历史副本和已被手册取代的资料，不重写 Git 提交历史，也不删除业务数据。Git、ECS 发布与原生商店分发分别记录，不因设定版本号而标记未完成能力为已验收。
