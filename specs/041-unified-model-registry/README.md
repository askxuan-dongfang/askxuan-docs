# 统一模型库与用途选择

> **Status**: ⏳ In progress · **Priority**: Medium · **Created**: 2026-10-14

## Overview

管理员先在统一模型库登记模型，再从同一目录按能力选择聊天、Embedding 建索引、Rerank 重排和文档理解。保留现有聊天连接与知识模型，密钥不重复填写或回显；同一语言模型可用于聊天和文档理解。

## Design

- 统一目录聚合现有聊天连接、已登记的独立语言模型和 WeKnora 模型；按用途及名称筛选，支持按需测试连接并显示容量。
- 新增语言模型独立保存连接与密钥，运行时按所选模型路由；配置沿用加密持久化、修订检查和请求快照，不能把当前生效连接覆盖成另一个模型。
- 聊天与视觉模型从语言模型中选；建索引只选 Embedding；重排只选 Rerank；文档理解可复用已登记语言模型，由后端安全准备知识引擎适配，浏览器不读取密钥。
- 平台默认用途用于新配置，智能体草稿和知识库使用同一目录。现有知识库的 Embedding 固定，换模型需新建并重建索引；保留历史发布和回滚依赖。
- 未登记、用途不匹配或连接失败的模型拒绝绑定；未知模型使用显式配置的容量，已知 Agent Plan 使用官方容量限制。使用中的模型禁止删除。
