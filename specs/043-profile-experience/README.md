# 头像上传与双端个人体验优化

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-10-15


## 范围

在现有经典配色、衬线标题和卡片层次上优化客户端个人中心与大师工作台。保留现有订单、钱包、服务履约和认证业务，减少重复入口及需要填写技术字段的交互。

## 设计

- H5 与两个原生 iOS 客户端使用照片选择、圆形裁剪预览、缩放与微调，输出 512×512 JPEG。保存资料时才上传，取消编辑不写入；上传成功但资料失败时复用已上传结果。
- 复用带 JWT 与真实图片 MIME 检测的 `/files/upload`。资料更新使用可选字段区分未修改和明确清空，支持恢复默认头像及清空简介。
- 客户注册成功后可设置头像与昵称或跳过；后续保存失败不影响账户已注册状态，不重新提交注册。
- 个人中心突出头像、钱包、服务进度与三种订单，只保留一个消息入口，弱化尚未开放的成长记录。
- 大师工作台先展示待处理预约、履约及今日预约，再放常用功能和经营数据。当天查询由服务端 `date=YYYY-MM-DD` 过滤，保留 JWT 大师归属条件与分页。失败显示不可用，不伪装为零条。
- 大师专长由逗号输入改为点选及自定义添加，认证身份只读展示；不改变服务标签、定价及可预约能力。
- 动效复用既有时长和 easing，只用于弹层、操作反馈；键盘和减少动态效果模式即时响应。
