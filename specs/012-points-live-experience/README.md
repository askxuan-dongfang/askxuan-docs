# 真实积分活动与积分中心体验

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-09-10


## 目标与边界

“幸运转盘”标签直接显示游戏，去掉活动卡片的二次跳转和本地演示钱包。H5 与 iOS 均读取服务端积分、参与记录和奖品订单；旧演示数据不转为真实积分或中奖，H5 负数旧链接重定向到相应正式分类。无活动或接口失败时显示真实空态/重试，不生成替代记录。

一期一人一码、真实积分扣除、平台奖品预算、截止时间与原有审计履约继续保留。转盘动画使用服务端结果定向停转，动画扇区面积不代表中奖概率。后台仍在统一管理平台“营销活动 / 积分活动”和“商城管理 / 积分商城”，不新增管理平台。

## 界面与交互

- H5 转盘分类直接加载进行中的一期，存在多期时可切换；主画面为转盘、奖品、抽奖按钮、可用积分。规则/概率/截止及个人参与码/公告分别收进规则和记录弹窗。
- 真实扣分前展示消耗与剩余余额，处理与动画期间禁用操作；中奖弹窗可直接进入领奖。刷新恢复服务端结果，同一期仅返回已有参与。
- 积分中心重做余额卡、规则弹窗、两个活动入口、分段导航、积分明细、商城搜索/库存/积分差额、兑换后余额、订单履约步骤。关联单号、地址与历史时间按需展开。
- H5 兑换使用原生 dialog；重试保留原请求键和已确认参数；数量限制在库存与 99 件内。加载骨架、真实空态、负余额、错误重试、键盘关闭、窄屏和减少动态效果均覆盖。
- iOS 原生同步直接转盘、服务端记录、余额卡、规则 sheet、明细展开、商品积分差额、兑换后余额与履约步骤。无独立本地积分账户。
