# AI 阅读、私聊角标与大师广场体验

## 范围与隔离

从 2026-09-11 当前代码继续，使用独立 Git worktree 和功能分支实现。原会话正在开发体验商城，本任务不编辑其工作区，不改商品、购物车、订单、支付、财务与共享图片组件。发布候选必须包含原会话最新已提交的商城成果；静态发布前校验线上目录未变更，保留商城/寺院兼容入口。

## 设计与实现

- H5 AI 对话与完整报告共用安全 CommonMark/GFM 渲染，支持标题、强调、列表、引用、表格、代码和链接；流式片段可继续渲染。禁止解释原始 HTML，不自动加载模型提供的远程图片。用户输入保留原文。iOS 共用分块 Markdown 阅读组件。
- H5 私聊角标原来取自 `/messages/unread-count`，因此站内通知 16 条会误显示成私聊 16。改为只聚合去重后的会话 `unreadCount`；后端未提供时不显示未知数量。双会话接口都失败时显示重试，不能显示为没有会话。
- H5 对话内直接嵌入广场。发现、关注、图文、视频、关键词和最新/热门筛选写入 URL；双列内容卡片、作者入口、图片放大/滑动、沉浸视频、内容分享和分页评论形成浏览链路。请求隔离防止旧筛选污染新结果，点赞/关注/评论防重复提交。不可播放媒体明确降级；视频不会被当作封面图片请求。
- iOS 广场同步筛选、搜索、分页、作者名称、点赞/关注状态、评论分页及提交锁。视频播放器保持生命周期，离开页面或应用后台时暂停。
- 作者工作台支持已上传素材预览、排序、删除、编辑回填和数量限制；发布失败保留编辑内容。
- 后台帖子审核提供图文/视频实际素材预览。审核通过时，在同一事务中更新帖子、审核记录及所属媒体的审核状态，避免帖子通过而附件不可见。数据库迁移只为 `community_user` 增加媒体 `audit_status`、`update_time` 列更新权，不创建示例内容，不改商城数据。

## 接口约定

`GET /api/v1/community/feed` 新增 `following`、`keyword`、`sort`，保留 `type/beliefCode/page/size`。`type=article|video`，兼容旧 H5 的 `image`；`sort=latest|popular`；关键词最多 80 字，SQL 参数化并转义 LIKE 通配符。关注过滤发生在分页前，身份只取可信请求头。响应新增 `following`、`coverUrl`，素材可包含 `url/coverUrl/duration`。普通媒体读取仍要求登录且 ready + approved 或归属本人，审核预览仅走平台角色校验后的后台接口。公开评论不能读取已下架帖子的评论或内部审核备注。
