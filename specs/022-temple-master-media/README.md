# 寺院与师傅图片完善

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-09-11


## 目标

首页热门寺院使用静态占位图标，独立师傅头像为空；详情页没有可浏览相册。为当前公开的 9 座寺院、13 位演示师傅补齐预览图、头像或图标、详情图片，并在 H5 各入口统一展示。

## 设计

- 寺院使用逐一对应的真实实景照片，保存原作者、来源、许可和本地版本。
- 演示师傅使用各自独立的 AI 生成人像，详情展示“AI 生成 · 演示形象”；场景图与寺院实景分别说明，不冒充真实活动记录。
- 素材随 H5 Git 和 CI 发布；以对象 ID、名称及原媒体地址约束演示素材绑定，后台后续上传的新图片优先显示，不覆盖运营数据。
- 归一化保留寺院详情接口已有 images，合并本次媒体清单；新对象无清单时照常使用接口图片。
- 可点击相册大图，支持上一张、下一张、关闭、键盘与图片失败回退。头像使用轻量版本，详情保留清晰大图。
- 保持公开列表及审核、上架状态，不将待审核的 T005/M005 暴露到客户端。

## 验收

- [x] 9 个寺院和 13 位师傅都有独立媒体且来源明确。
- [x] 首页预览、列表头像、详情封面与相册一致，图片加载失败可回退。
- [x] 320、390、587、768px 验证与相册交互通过。
- [x] H5 构建、CI 发布、线上媒体格式及逐对象浏览器验收通过。

## 实施结果

- H5 提交 `bacadb3df45d9877f92776bfdde42402b62bf39f`，Actions 运行 `34562702872` 自动部署成功。
- 9 座寺院、13 位师傅，每个详情两张图片；35 张独立原图输出 70 个 JPEG 文件。生成方式为内置 image_gen；作者许可与提示词随源码归档。
- 159 项媒体归一化断言、70 个线上图片格式与哈希检查、61 项 ECS 发布/健康检查均通过。浏览器逐一打开 22 个详情页确认图片加载；首页 8 张预览全部正常。
- 图片属于 H5 版本化展示资源，没有更改数据库图片字段；运营新上传优先、待审核对象不变。后续在 H5 媒体清单与素材目录维护并走既有 CI。
