# DIY 大画布与直接拖拽编辑

> **Status**: ⏳ In progress · **Priority**: High · **Created**: 2026-10-20 · **Tags**: product, diy, cross-platform

## Overview

用户 2026-10-20 追加：扩大上半部实际渲染面积，取消可见珠子编辑菜单，直接拖珠换位、拖出松手删除。广场和我的设计压缩顶部；作品详情只读，管理回到我的设计。承接 [053 无框画布](../053-diy-open-canvas/README.md)。

同轮目录追加承接 [054 悬浮筛选](../054-borderless-controls-and-floating-filters/README.md)：类型行最右固定定位图标与地区按钮，无动画地区浮层与宗派浮层互斥，移除独立地区行并协调服务标题字号。

首页追加固定 2 × 2 的等大四卡，常规高约 96–104px；屋檐、人物、手串、星纹四套原创低对比底纹；首页搜索全站功能及内容，目录只查当前寺院 / 师傅的名字、标签、服务和地区，并与既有筛选组合。

完整页面、状态与交互见[标准产品方案 v3](../../docs/product/DIY大画布与直接拖拽产品原型方案.md)、[可操作原型](../../docs/product/prototypes/diy-direct-drag-v3/index.html)和[验收记录](../../docs/reports/2026-10-20-DIY大画布与直接拖拽.md)。

## Design

- 390 × 844 默认实际渲染高度目标 ≥300px；放大手串可见尺度，仍避让工具、保证材料与底栏可达。
- ≥6px / pt 起拖；冻结起拖视角下完整绳圈、珠子及配件外沿的投影凸包；锚点外距严格 >24px / pt 才待删，内孔安全。
- 正常松手才提交；拖回取消待删，Escape / pointercancel / 失焦 / 多指取消整个手势。一个有效操作一条历史。
- 不保留可见编辑菜单；键盘和 VoiceOver 等价移动 / 删除 / 撤销。平面降级遵循同一规则。
- 广场 / 分享的详情只有预览、作者、用料与复制并编辑；本人公开作品同样只读。作者只用接口真实 ID。
- 我的设计作品卡直接进入编辑器，发布 / 下架独立。保存已发布作品按现有合同转私密，明确提示需重新发布；不引入后台发布快照。
- 寺院 / 师傅的地区与类型同行；地区按钮固定右侧，左侧类型横滚。两浮层互斥、外点不穿透、Escape 归还焦点，打开不挤动列表；定位图标不触发定位权限。
- 首页固定 2 × 2，四卡同尺寸且有原创底纹，前景只保留图标与名称；删除副标题和独立积分横条，大字仍两列并同步增高。搜索按全站 / 本目录区分，整合既有接口，不新增后端接口；遵循真实数据、既有权限与组合筛选。
