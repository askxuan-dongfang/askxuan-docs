# 固定筛选字典与地区示例、寺院详情重整

> **Status**: 📦 Archived · **Priority**: Medium · **Created**: 2026-10-13

## Overview

用户要求地区切换时保留后台配置的固定筛选，补齐港澳台、东南亚与沿海信俗标签，并为每个标签提供多条寺院与师傅示例；同时优化寺院详情。

## Design

- 一级分类保留汉传佛教、藏传佛教、道教、民间信仰，新增南传佛教。七个心愿入口不变。
- 二级采用「宗派 / 信俗」多选关联：24 项发现标签，涵盖禅、净土、天台、华严、藏传四派、上座部、全真、正一，以及妈祖、关帝、城隍、王爷、福德正神、保生大帝、哪吒、洪圣、黄大仙、九皇爷、大伯公、拿督公、三山国王。不是穷尽式宗教学分类；神明信俗可以跨一级分类关联。
- 新增 `directory_tag` 和 `provider_directory_tag` 两张表，由寺院服务维护。师傅服务仅获 SELECT 权限。管理平台的「筛选标签」支持名称、排序、启停；身份与领域匹配值创建后固定，避免改名破坏筛选。
- 侧栏服务读取统一 S001–S013 目录；身份与领域读取固定字典。地区与信仰只影响结果，不裁剪任何标签。无结果仍保留已选条件，并提供清除筛选。
- 目录分批读完后再应用客户端组合筛选，避免第 100 条以后的资料不可发现。寺院服务条件进入 SQL 分页前，确保 API 总数准确。
- 72 个虚构演示场所、72 位独立师傅和 72 位寺院师傅；每个宗派 / 信俗至少各 3 例。固定身份、擅长领域、地区、13 项服务均有至少 3 例。种子脚本验证覆盖矩阵，INSERT IGNORE 可重复执行，不覆盖既有资料。
- 新例使用 DT/DM/DW 专用编码、演示名称、零评分、明确虚构介绍；不创建真实资质、评论、订单或付费咨询。寺院师傅的服务与所在寺院匹配；三组兼祀示例验证多标签。

| Before | After | Why |
|---|---|---|
| 地区结果推导侧栏选项 | 固定后台字典，零结果保留 | 筛选规则可理解且可维护 |
| 四类信仰覆盖不足 | 五类信仰 + 24 项宗派 / 信俗 | 区分宏观类别与具体传统 |
| 寺院大图、重复头像、默认介绍 | 单张紧凑封面、统一返回与收藏、默认服务 | 先找到可办事项与费用 |
| 四标签含空文创 | 服务预约 / 寺院介绍 / 师傅团队 | 减少一级信息，文创保留在介绍中 |
| 图标大卡堆叠 | 紧凑服务行、费用与时段并列 | 提升小屏可扫读性 |
