# 地区标签与预约入口一致性

> **Status**: 📦 Archived · **Priority**: Medium · **Created**: 2026-10-13


## 用户要求
寺院和师傅新增大陆、香港、澳门、台湾、东南亚等地区标签，管理平台可设置。双轨的指定师傅预约必须存在该用户对该师傅的有效付费咨询。服务入口只允许选择确实开放当前项目的师傅。统一 H5 全局返回按钮位置。

## 设计
- region_tag 保存编码、名称、排序、启停状态；provider_region 保存寺院或师傅的一项地区归属。原城市和地址保留。
- 寺院绑定师傅默认继承寺院地区，显式设置可覆盖；清空后恢复继承。独立师傅不推断地区。
- 地区筛选在服务端分页前执行；公开字典只返回启用项；停用保留已有归属。管理平台地区字典及归属接口仅 platform_super。
- 付费咨询必须同一用户、同一师傅，支付成功、状态 active、费用大于零、已开始且未过期。创建、订单支付与余额收银台均校验；已完成付款的订单查询不受后续咨询到期影响。
- 全寺执行不指定师傅，维持寺院公共预约路径。本人服务标签与寺院上架服务取交集，目录推荐关联不表示实际可执行。
- 导航栏统一高度 56px，加顶部安全区；横向留白 12px，返回按钮 44px。普通页面、封面详情、钱包、积分和轻体验均使用同一导航规则。标签栏置于导航下方。
- 列表顶部采用流派文字页签与浅色地区选项，避免两个同权重胶囊栏；390px 下固定区高度从 184px 收紧到 152px。师傅卡片仅保留头像、姓名、地区、可约服务和起价。
- 寺院服务预约页按服务介绍、执行方式、费用明细组织；纵向选择寺院统一安排或指定师傅，底部同时显示完整费用与继续预约按钮。深浅主题共享布局。
- 六位已上架独立演示师傅补齐演示地区：W001/W006 大陆，W002 香港，W003 台湾，W004 澳门，W007 东南亚；只用于筛选演示，不表示真实所在地。原有其他归属不覆盖。

## 接口
- GET /api/v1/regions：启用地区。
- GET/POST /api/v1/admin/platform/regions；PUT /:code：地区字典维护。
- PUT /api/v1/admin/platform/regions/providers/:kind/:id：保存地区；kind 为 temple/master，regionCode 为空时清除覆盖。
- GET /api/v1/bookings/eligibility?masterId=：当前登录用户的咨询资格。
- 寺院与师傅列表支持 regionCode，返回 regionCode/regionName；师傅附带 regionInherited。
