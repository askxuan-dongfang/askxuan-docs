# 邮箱与密码认证

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-09-14


## 范围与决定

采用邮箱验证注册，邮箱／用户名 + 密码 + 图片验证码登录，邮件找回密码。短信未接入时隐藏入口。管理台与师傅端账户由管理员开通，不开放公众注册。用户确认尚无 SMTP 服务，当前交付可配置 SMTP 和隔离本地收信联调，不发布到生产。

代码隔离在 `artifacts/email-auth-20260915/{backend,frontend}`，H5 是 frontend/apps/web-h5 内的独立仓库。三个仓库使用 `codex/email-auth-20260915` 分支，原工作区保留。

## 实现

- 新增 auth_identity，保留原业务用户 ID，邮箱唯一，记录邮箱验证时间与注册协议版本。新增账号允许手机号为空。
- Argon2id 密码；Redis 验证码 HMAC、一次性消费、过期、重试次数和频次限制。重新发码重置旧错误计数。
- SMTP 587 STARTTLS／465 TLS；明文仅允许显式本地 loopback 测试。真实配置只保存在服务端。
- 用户／管理账号分域，角色仍来自服务端；去掉演示验证码、明文密码和旧手机注册旁路。
- JWT sid 关联服务端会话；网关检查会话，刷新保留 sid。改密撤销全部同身份会话，退出撤销对应会话，包括访问令牌已过期的情况。并发登录在签发前复核凭据，防止旧密码跨过重置边界。
- H5 与两个 Web 管理台、两个 iOS 端均改用同一认证契约。保留品牌和主题，提供图片刷新、邮箱发送倒计时、错误状态、禁用重复提交。H5 刷新采用共享请求与账户版本比较，保护新登录不被迟到响应覆盖。
- 运维绑定工具验证邮件后迁移既有账号，保留订单／角色关系，拒绝覆盖已有验证身份。
