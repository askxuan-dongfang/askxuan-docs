# 方案 A：现有界面的渐进视觉优化

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-10-15 · **Tags**: design, frontend, ios

## Overview

保留既有页面、业务操作和导航，用方案 A 的留白、层次和组件细节统一 Web、H5 与 iOS。

## Design

用户选择「方案 A 松风留白」，同时要求在原版上优化，许多交互逻辑保持不变。因此本轮只修改共享样式与原生组件的绘制属性：

- 保留暖白、墨绿、朱砂、柔金与宋体标题；两个管理台继续使用既有深绿侧栏。
- 后台标题在桌面适度放大，副标题和统计标签提高可读性；统计图标收至 40px，为数值留出空间。
- 卡片边框和投影减轻，表头背景更柔和；按钮采用实色品牌背景，圆角和描边更一致。
- H5 保持首页模块顺序、七个祈愿分类、底部导航、表单和弹窗行为；保留桌面/手机原有断点。
- 两个 iOS 客户端只同步共享卡片和主次按钮外观；原生返回手势、动画时序、加载/禁用状态保持原样。
- Mac 管理端继续加载两个管理平台；本轮无需改动容器或重新安装 Mac 应用。

不修改路由、事件处理、请求契约、权限、状态管理或业务数据；不增加新的动画依赖。已有短反馈、键盘焦点和减少动态效果继续有效。
