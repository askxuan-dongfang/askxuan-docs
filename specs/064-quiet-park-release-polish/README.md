# 园区视觉精修与生产上线

统一首页栏目与卡片边距，改善园区模型和横屏视野，按受控 PR、正式 CI 产物及可回滚流程上线。状态保持 in-progress，直到 H5 发布和线上入口验收完成；建模精致度仍需用户确认。

## Design

- 首页三个标题共用字号、字重、主题正文色与左边线；园区卡片沿用首页两侧留白。
- 手机竖屏先显示“横屏进入”，确认后申请全屏及方向锁；浏览器不支持时使用旋转后的横向页面。平板及较大屏幕直接使用横向宽视野；切换方向保留房间与练习状态。触摸 client/page 坐标同步转换，R3F offset 坐标保持原值；手机画质仍按短边降级。
- 资产基础版为 2026.11.06.5，包含十二殿、人物16骨/5动作及 Blender 源。新主殿样板 2026.11.06.6 改为歇山屋顶、三开间柱廊、格扇与台基栏杆；其他十一殿沿用基础版，不能称为全园重新建模。庭院更新石铺、植栽和 NPC，并减少近镜头人物遮挡。
- 南传坐佛殿单独接入明尼阿波利斯艺术馆藏泰国金铜坐佛 17.116，来源和 CC0 许可随源模型及加工记录保存；不将其混用于汉传主殿。其余造像仍是原创示意，宗教形制需专业复核。[馆藏来源](https://collections.artsmia.org/art/12487)
- quiet 采用独立 Go module、CI scope、新 quiet_local 库、受限 quiet 用户及专用带密码 Redis；旧20服务输入指纹和 backend 配置契约保持一致。生产只接收正式 CI 构建的固定源 SHA 产物，运行层使用审阅后的固定摘要 Alpine。
- 公网代理仅到 loopback18196；HTTPS origin 精确白名单；跨域名共享 WS400/IP40、记录 POST 全园60r/m/IP20r/m，超额429保留设备副本；健康 Ping 仅限 loopback。阈值是 beta 防护边界，不是容量验收结论。
