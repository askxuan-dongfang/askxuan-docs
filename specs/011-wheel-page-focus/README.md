# 转盘主页面精简

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-09-10


## 交互目标

用户在浏览器标记了人数/奖品/概率、活动进度、参与码和开奖公告四处冗余，要求转盘采用常见即时抽奖页面。旧版将奖池的详情展示方式复用于转盘，导致抽奖后仍堆叠多块重复信息。

H5 和原生 iOS 分别实现独立转盘布局，主页面仅展示活动名称、转盘、奖品预览、抽奖按钮和可用积分；主画面下方保留“抽奖记录 / 我的奖品 / 活动规则”。奖池继续保留截止开奖所需的进度、人数和公告。

## 信息与功能保留

- 移除转盘常驻人数统计、进度卡、参与码卡和公告卡，取消底部固定重复按钮。
- 活动规则弹层保留活动时间、数量、参与情况、概率、积分规则与奖品说明。
- 抽奖记录弹层保留本期结果、参与码、积分消耗与时间；开奖留档折叠查看，并可进入全部参与记录和领奖。
- 即时结果弹窗显示中奖/未中奖和奖品，不再重复展示参与码；抽完后的主按钮为“查看本次结果”，不会再次扣积分。
- 两端原有一期一次、幂等扣积分和正式/演示隔离均保留。本次为交互精简，未更改后台抽奖算法、预算、余额、活动配置或数据。
- 修复 H5 同一路由内通过“我的奖品”链接切换分类时，查询参数与页面标签不同步的问题。
