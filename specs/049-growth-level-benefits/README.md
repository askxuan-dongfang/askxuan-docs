# 五级成长体系：权益、折扣与结算规则

> **Status**: ⏳ In progress · **Priority**: High · **Created**: 2026-10-19 · **Tags**: product, growth, commerce


> `growth-v1` 产品方案，计价、冻结、礼券与整单退款已实现并通过 MySQL 集成回归。等级及成长值使用[成长基础规则](../048-growth-level-foundation/README.md)。折扣按人民币结算，9.8 折 = 付标价的 98%，不写成“98 折”。

## 五档权益

所有等级均有成长档案、记录查询、基础客服与正常售后。L2 起有对应等级徽章；以下新增非价格权益向高等级继承，优惠按当前等级一档执行。

| 等级 | 指定商品及 DIY 材料 | 参与的固定服务 / AI 报告 | 首次升级礼券 | 新增非价格权益 |
| --- | --- | --- | --- | --- |
| L1 初识 | 原价 | 原价 | 无 | 基础成长档案 |
| L2 同行 | 9.8 折 | 原价 | 满 ¥100 减 ¥5 | 等级徽章，可隐藏 |
| L3 笃行 | 9.7 折 | 9.9 折 | 满 ¥200 减 ¥10 | 月度成长回顾 |
| L4 致远 | 9.5 折 | 9.8 折 | 满 ¥300 减 ¥20 | 平台客服优先分流 |
| L5 恒久 | 9.2 折 | 9.5 折 | 满 ¥500 减 ¥50 | 年度数字成长纪念卡 |

月度回顾为成长账本统计，每月 1 日生成上月数据；升级后可查最近一个完整月。纪念卡每年 1 月 1 日生成上一年的个人里程碑，首次达 L5 可生成上一完整年（无记录则显示暂无）；可保存分享且默认隐藏金额。二者为确定性内容，不赠 AI 次数、不加工私人笔记，不承诺预测效果。

客服优先仅在同一紧急程度的普通平台咨询队列内生效，显示实际工作时段与排队情况；不改变退款裁决、服务时长、预约时段或安全问题优先级，不承诺专属师傅或 24 小时响应。首期没有免运费、实物礼包、生日礼和付费购买等级。

## 折扣范围

| 费用 / 交易 | 等级折扣 | 交易成长值 |
| --- | --- | --- |
| 普通商城、东方珠作标记参与的商品 | 商品档 | 合格净实付计入 |
| DIY 材料 | 商品档，按材料行标记 | 合格净实付计入 |
| DIY 制作费、定制加工费 | 首期不打折 | 固定付费项目计入 |
| DIY 加持/师傅附加服务 | 仅参与的固定服务费走服务档 | 固定服务实付计入 |
| 寺院预约、大师直约、即时咨询 | 提供者选择参与的固定服务费走服务档 | 固定服务实付计入 |
| AI 报告人民币解锁 | 平台选择参与的报告走服务档 | 成功解锁的净实付计入 |
| 运费、代收费用、随喜/捐赠 | 不打折 | 不计 |
| 充值、保证金、提现/结算、创作收益入账 | 不打折 | 不计；真实余额后续消费按消费项判断 |
| 积分商城、转盘、奖池、积分解锁报告 | 不减积分、不改概率 | 不计 |
| 体验商品、模拟交易、非现金赠额 | 仅可独立演示效果 | 不进入正式成长账本 |
| 限时特价、秒杀、已锁协议价 | 与等级价择优，不重复折上折 | 实际合格净支付计入 |

参与名单以 SKU/材料项/服务项目为粒度，默认关闭；门店或提供者“参与”不等于其全部服务参与。费用不能拆出固定服务、随喜及代收项时，先不接入该项目。未参与时明确展示原因，不能给整单标“9.2 折”。

## 礼券与使用上限

- 每档礼券终身自动发一次，跨级补发所有首次跨过档位；补发重试不重复。券在发放后 **30×24 小时**有效，每单最多一张，只适用参与的普通商城及 DIY 材料，不覆盖任何服务、运费或随喜。
- 券门槛按适用行正常销售价合计判断；首期不与活动价、等级折扣或其他券叠加。系统比较合法方案的整单应付金额，默认最优惠；同价优先不消耗券的方案。用户可主动改选，付款前展示最终金额。
- 正常升级券总面额上限为 ¥85/账号，首期不设月度券和成长值换券。启用前配足模板和券预算，发券锁定对应面额、到期/撤销释放，兑换转实际成本，避免领到券却无预算使用。部分退款不退券；整单退款且原有效期未过、未因降级撤销时恢复同一张券和预算，期限不延长。
- 退款/作弊降级时，撤销门槛高于当前等级的未使用券；已使用不追补差价。再次升回同级不重发；违规套利保留原账本，暂停新优惠并人工核对。
- 等级折扣封顶：每个原始结算单商品优惠 ≤¥100、服务优惠 ≤¥50；每账号每自然月两类合计 ≤¥300，按上海时区。礼券面额单列，不占等级折扣月额度。
- 结算报价展示本单减免、单次上限、当月已用/冻结/剩余。下单冻结额度，支付消耗；超时/取消释放。退款按原分摊减免释放当月额度，跨月不返还旧月额度；不能通过拆子单重置原结算单上限。

## 计价、订单与退款

金额使用整数分，规则倍率用整数万分比（9.2 折 = 9200）。每行等级优惠 = 向下取整(正常销售金额 × (10000 − 倍率) / 10000)，不足一分舍去。正常销售价为真实当前售价，不以虚构划线价打折。

先计算商品与服务两组，再分别应用单次上限，最后应用账号月剩余额度。压缩后的减免按各行原始减免比例分摊，先取整分，再按余数降序分配尾分；同余数按稳定行 ID 排序。礼券在适用行按金额比例同样分摊。所有分摊合计必须与订单总减免相等。

首期计算四类互斥的整单方案：正常价、活动价、等级价、单张可用券价；活动方案可在不同项目采用其已公开活动价，但不能额外叠加等级价/券。任何被锁定的协议项目不可参加其他方案。比较结果与排除原因服务端返回，不能由各端各算一套。

报价有效期 5 分钟，下单原子校验并冻结额度/预算/券，争抢失败返回新报价供确认。订单价格及资源冻结 15 分钟或原业务更早的付款期限；付款处理中延续锁定直到查单确认，不凭客户端超时释放。升级/降级或规则变更只影响新报价；过期须重报确认，绝不静默多扣款。

订单保存等级、规则版本、原销售价、各行优惠/净实付、预算和券来源快照。原单退款按各行原净实付及数量分摊，尾分规则一致，累计退款不超该行实付；不按现等级重新定价、不追扣优惠凑单差额。非指定项目的金额退款需先明确归属，才能冲回成长及分摊收入。

## 谁承担优惠

首期只开放平台承担：商品折扣、服务折扣和升级券全部从平台营销预算支付。服务提供者自主参与；在固定服务原销售价基础上按原合同计算其应得，不因客户等级减少。平台补足优惠并单列营销成本；不能把用户实付等同于提供者结算基数。

项目上线前必须登记正常销售价、履约/采购成本、平台费用、提供者保底、最高营销补贴和预算归属。未配齐或预算不足，停止该项目新优惠报价并展示原因；已下单冻结预算继续履行。没有已批准预算和最低贡献约束的 SKU/服务默认不参加，不用前端临时改折扣兜底。

创作奖励保留现有合同：**DIY 材料用户实际支付的 5%，单笔最高 ¥20，完成 7 天后结算**；等级优惠/券分摊会减少其材料实付基数，平台补贴不算材料用户实付。奖励退款撤销继续遵循现有奖励快照规则，不用成长值的部分冲回规则覆盖。若未来要按折前金额保作者收益，需单独调整奖励合同与费用预算。

## 算例与实施门槛

- L3：商品 ¥200、参与服务 ¥100、运费 ¥10、随喜 ¥20 → 等级减 ¥6+¥1，应付 ¥323；成长基数 ¥293，完成观察期得 293。
- 同单有“商品满200减10”券：应付 ¥320、成长基数 ¥290，优于等级方案，默认用券；两者不叠加。
- L5：商品 ¥2,000、服务 ¥2,000、运费 ¥20 → 原减 ¥160+¥100，单次封顶变为 ¥100+¥50，应付 ¥3,870；若月剩余 ¥120，两类减免按比例变为 ¥80+¥40，应付 ¥3,900。
- ¥19.99 商品的 L2 减免为 floor(1999×200/10000)=39 分，实付 ¥19.60；不得某端算 ¥19.59。
- 服务原价 ¥100、合同提供者份额 ¥85，L5 用户付 ¥95：提供者仍得 ¥85，平台折前份额 ¥15 扣营销补贴 ¥5 后为 ¥10（未扣其他成本）。这是算例，不假定所有合同都是 85/15。
- [x] 统一报价、优惠/预算冻结、订单分摊快照和退款对账；新字段先形成生产者/消费者契约，旧金额字段不能默默改义。
- [ ] 现有现金钱包仅支持整单退款；本方案的部分退款是目标口径，未实现的业务不得宣传已支持，接入成长体系前至少验收该业务实际支持的退款闭环。

## 首期实现边界（2026-10-19）

服务端统一整数分报价、5分钟报价/15分钟冻结、单次与月封顶、预算、供方同意、升等级礼券和不可变原单快照；H5 与原生收银复用该结果。等级折扣开关默认关闭，等级和礼券预算均为零；没有获批预算时礼券显示待发放，不承诺可立即使用。

现有现金钱包仅整单退款，已覆盖净额全退、返券资格、同月额度释放和跨月不返旧额度；部分退款继续作为后续业务能力，不能显示为已支持。当前业务源无独立活动售价字段，活动价候选算法已实现，但生产尚未配置该来源。实际支付渠道和提供者财务账单联验仍须在开优惠前完成。
