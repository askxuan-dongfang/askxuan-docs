# DIY 单一 3D 交互工作台

> **Status**: ✅ Complete · **Priority**: High · **Created**: 2026-10-15 · **Tags**: h5, ios, diy, design

## Overview

制作页统一使用可编辑 3D 手串，移除 2D/3D 工作模式切换。保留松绿、米白、古金与品牌字体，压缩重复说明与工具，避免预览和材料在手机上相互遮挡。

## Design

- 桌面左右分区，移动端上方工作台、下方独立滚动材料库；草稿、价格、保存、定制保持原契约。
- 点选珠子显示复制、删除、顺序工具；拖珠在真实三维平面投影后排序，拖空白旋转、双指缩放。每次放下只记一次历史，取消手势不改变设计。
- 序列按钮提供键盘、辅助技术与 WebGL 不可用时的编辑路径。视角不随选中、材料筛选或数据变更重建。
- 材料使用已有照片纹理与低对比程序纹理，按需渲染；没有摄影资源的材料不宣称实拍还原。
- iOS SceneKit 与 H5 同步入口、选珠、排序、复制/移除、草稿及紧凑布局。
