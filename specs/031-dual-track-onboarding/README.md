# 双轨大师认证与寺院入驻

> **Status**: ✅ Complete · **Priority**: Medium · **Created**: 2026-09-15


统一用户名／邮箱、密码与图形验证码登录；注册及找回通过邮箱验证。C 端保持普通用户注册，大师端提供独立认证注册及寺院分配账号激活，寺院管理平台提供机构入驻。平台人员仍由内部授权。

## 身份与流程

- 独立大师：大师端注册申请人账户 → 草稿 → 提交 → 平台通过／退回补充 → 大师工作台。
- 寺院：寺院平台注册经办人账户 → 机构证明及管理授权 → 平台审核 → 创建寺院并绑定经办人。
- 纳管大师：寺院建立并认证本寺大师档案 → 分配邮箱和用户名 → 本人在大师端验证邮箱、设置密码激活 → 登录使用。不可自助注册成纳管身份。
- 申请人无业务权限；后台核验实时角色、账号状态及寺院归属。审核版本锁避免重复开通。寺院只能分配／停用／恢复本寺纳管账号。身份转换不通过自助改字段实现，既有归属关系保留。
- 原 user/admin 身份域及 ID 保留，不凭相同邮箱自动合并历史账号；跨端统一的是认证协议与凭据规则。
